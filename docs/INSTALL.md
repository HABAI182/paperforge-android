# 安装、更新与常用入口

PaperForge是个人非营利的Android文档工具，无账户、广告、水印和订阅。Android8.0及以上，普通64位ARM手机安装完整功能版即可。

## 下载安装

当前正式版是 2.0.1。从[最新公开发布页](https://github.com/HABAI182/paperforge-android/releases/latest)下载 `PaperForge-2.0.1-full-arm64-v8a.apk`。`release-manifest.json`和`SHA256SUMS.txt`是核对文件，无需安装。GitHub自动提供的源码压缩包也不是安装包。

一个完整APK已包含扫描、OCR、阅读、Office排版、表格重建、特殊格式和联网工具。系统桌面只有一个PaperForge图标。可覆盖原主应用并保留文档，不需要先卸载。旧Office、格式和联网扩展已不是运行依赖；旧联网工具中的历史结果需自行另存后再决定是否卸载。

本项目公开后可直接下载，无需PaperForge账户。自定义私有仓库时，浏览器仍需相应访问权限。

## 在手机内更新

进入**设置 → 检查更新**。页面显示“当前已是最新版本”“发现新版本”或连接失败等明确结果。找到适配的新版本后，由你选择下载并核对SHA256、应用身份和签名，再选择安装并打开Android系统安装器。安装确认由系统显示；首次可能需要允许“安装未知应用”，允许后返回即可继续。下载中可暂停并保留断点。

完整包新装默认正式版渠道；已有渠道和开关保留。自动检查默认关闭，手动检查本身不开始下载；开启自动更新后的行为见下文。安装仍由系统确认。仓库、渠道和访问凭据收在“仓库与访问凭据”中。

私有仓库需要此仓库Contents只读的GitHub fine-grained token，凭据加密保存在本机，不放进APK。仓库公开后可清除令牌直接检查。网络不可达或GitHub限流时可稍后重试，也可从设置中“使用说明”下方的“项目主页”进入发布页。

## 三个主页面

| 入口 | 常用内容 |
|---|---|
| 文档 | 最近、全部、收藏；搜索、导入、扫描、继续阅读、多选和回收站 |
| 工作台 | 扫描与识字、格式转换、PDF工具、文档整理、任务与流程、连接与智能 |
| 设置 | 版本、更新、GitHub，以及外观、扫描、识字、导出、高级和隐私偏好 |

文档顶栏“视图”切换列表/封面；“全部”右侧按钮展开详细筛选；工具右侧菜单可固定到常用，工作台最多显示四个快捷入口。工作台搜索跨分类查找功能与格式。

扫描PDF默认不做OCR，导出原比例纸张、标准清晰度与86%图片质量。需要文字层时再明确开启；文件改名保留输入的名称，真实重名才做冲突处理。本次速度迁移关闭扫描后自动 AI 精修；仅原默认 97/90 的相机/导出质量迁为 94/86，其它自定义质量保留。精修可在扫描设置重新开启，或在高清修复中手动运行。

扫描、OCR和文件处理在手机运行。翻译首次需下载语言包，可选模型按需导入；自定义远程服务仅在你点击运行时使用。细节见[隐私](PRIVACY.md)、能力与当前范围、[组件来源与许可](../LICENSE_NOTICES.md)。

自动更新默认关闭。在“检查更新”页开启后，系统会安排每日检查；可选择 Wi-Fi 自动下载，完成校验后提示安装，最终安装仍需 Android 系统确认。关闭自动更新会取消对应后台检查/自动下载，手动更新仍可使用。

导出前可直接在对话框顶部“文件名”修改本次 PDF 名称；任务转入后台后，首页或编辑器顶栏的“任务中心”可查看进度。默认不需要等待可选 AI 精修完成。

本批 20005 的多页快门会先显示正在拍照，文件保存后再显示“已拍下第 N 页”；取景页保持多页默认。导出成功卡片的分享、保存、预览、打开为四个同色等大按钮，保存位置在下方展开。快速练习册已包含轻量前景识别；较慢的完整 DocRes 可在“扫描后自动深度 AI 精修”中选用。新算法处理新成片；既有成片不会被后台改写，重处理请使用保留的原片。详细对照与限制见 本批审核记录。

20006 继续使用同一 UI，在快速练习册和深度精修中追加浅灰残留清理，保留横线与前景保护。新成片生效，旧成片请用保留原片重处理后比较；参数与实测见 图像处理补强。
