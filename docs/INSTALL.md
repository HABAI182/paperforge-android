# 安装、更新与常用入口

PaperForge是个人非营利的Android文档工具，无账户、广告、水印和订阅。Android8.0及以上，普通64位ARM手机安装完整功能版即可。

## 下载安装

打开[1.2.0发布页](https://github.com/HABAI182/paperforge-android/releases/tag/v1.2.0)，下载`PaperForge-1.2.0-full-arm64-v8a.apk`并安装。`release-manifest.json`和`SHA256SUMS.txt`是核对文件，无需安装。GitHub自动提供的源码压缩包也不是安装包。

一个完整APK已包含扫描、OCR、阅读、Office排版、表格重建、特殊格式和联网工具。系统桌面只有一个PaperForge图标。可覆盖原主应用并保留文档，不需要先卸载。旧Office、格式和联网扩展已不是运行依赖；旧联网工具中的历史结果需自行另存后再决定是否卸载。

本项目公开后可直接下载，无需PaperForge账户。自定义私有仓库时，浏览器仍需相应访问权限。

## 在手机内更新

进入**设置 → 检查更新**。页面显示“当前已是最新版本”“发现新版本”或连接失败等明确结果。找到适配的新版本后，由你选择下载并核对SHA256、应用身份和签名，再选择安装并打开Android系统安装器。安装确认由系统显示；首次可能需要允许“安装未知应用”，允许后返回即可继续。下载中可暂停并保留断点。

完整包新装默认正式版渠道；已有渠道和开关保留。更新不会定时检查，也不会静默安装。检查更新本身不开始下载。仓库、渠道和访问凭据收在“仓库与访问凭据”中。

私有仓库需要此仓库Contents只读的GitHub fine-grained token，凭据加密保存在本机，不放进APK。仓库公开后可清除令牌直接检查。网络不可达或GitHub限流时可稍后重试，也可用设置顶部的GitHub入口下载。

## 三个主页面

| 入口 | 常用内容 |
|---|---|
| 文档 | 最近、全部、收藏；搜索、导入、扫描、继续阅读、多选和回收站 |
| 工作台 | 扫描与识字、格式转换、PDF工具、文档整理、任务与流程、连接与智能 |
| 设置 | 版本、更新、GitHub，以及外观、扫描、识字、导出、高级和隐私偏好 |

文档顶栏“视图”切换列表/封面；“全部”右侧按钮展开详细筛选；工具右侧菜单可固定到常用，工作台最多显示四个快捷入口。工作台搜索跨分类查找功能与格式。

扫描PDF默认不做OCR，导出原比例纸张、标准清晰度与90%图片质量。需要文字层时再明确开启；文件改名保留输入的名称，真实重名才做冲突处理。已有个人设置不会因升级重置。

扫描、OCR和文件处理在手机运行。翻译首次需下载语言包，可选模型按需导入；自定义远程服务仅在你点击运行时使用。细节见[隐私](PRIVACY.md)、[能力与当前范围](quality/V1.2.0-STATUS.md)、[组件来源与许可](../LICENSE_NOTICES.md)。
