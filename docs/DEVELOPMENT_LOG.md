# 开发与接续记录

## 2026-10-23 · 第一轮可执行版本 0.1.0

起点：空工作目录，有 JDK17，无 Android SDK/Gradle/adb。读取用户提供需求；采用补充的非商业定位，直接创建 Kotlin/Compose 工程。

完成：官方 Android SDK 与 Gradle 下载/校验、wrapper、Room 文档草稿、CameraX 连拍与矩形分析、稳定捕获门控、OpenCV 透视与滤镜、四角拖动放大镜、页序和撤销、后台 PDF 导出、系统另存/分享、PDF 懒加载阅读/缩放/跳页、合并/范围抽取/旋转/图像压缩/文字提取、内置中英文 OCR 与 TXT。

验证：本地 8 项、设备端 7 项；独立 pypdf/Poppler 检查生成 PDF；实际通过 adb 驱动模拟器界面完成权限拒绝/恢复、拍照、裁切、后台导出、系统保存和分享面板。具体命令和最终状态在 TEST_MATRIX 与 acceptance 中。没有真实手机测试结论。

修复要点：

- 相机自动拍摄在同一纸张稳定后锁定，移出视野或明显变化才重新触发。
- 裁切限制凸四边形，EXIF 旋正后使用统一归一化坐标；编辑清空旧 OCR。
- 阅读器缩放不阻断普通单指滚动；关闭旧 renderer 时捕获正确会话。
- PDF 抽取显式保留继承资源；文字提取按文字方向排序，解决 90° 页面逐字换行。
- OCR 取消后保留 native 工作输入，任务完成再释放 Bitmap；增加取消后重试验证。
- 输出预览按数据库中的路径复用文档记录；不能使用暂停订阅的首页缓存判断文件是否已登记。
- 文件写入先生成完整本地 PDF 并解析，再交给系统提供程序保存；外部保存逐字节读回核对。

## 下一步最小可执行任务

1. **ARM64 真机 M1 验收**：安装交付 APK，飞行模式拍真实 A4 十页（含倾斜、阴影、浅铅笔），纠偏、排序、导出并在外部阅读器打开；记录机型/Android/ROM、耗时、问题样本。不要重建已有工程。
2. 围绕真实样本调整边缘评分、拍摄 FOV/旋转映射、相机稳定预览和去阴影；当前 CLAHE 只是局部对比度基线。
3. 补 M1 高频体验：页面拖拽网格、重拍替换、批量应用滤镜、长按原图对比、导出 JPG/PNG。
4. 补 M2 文档工具测试与持久任务：PDF 转图片/水印/页级管理，100 页内存压力，工具的取消/后台恢复。
5. **独立 M3 项目任务**：结构化 OCR 四角与行序，嵌入可授权中文字体并生成透明文字层；通过不同旋转和外部阅读器搜索/复制后才标为“可搜索 PDF”。

源码在当前目录，可直接 Android Studio 打开；不要从最初 prompt 重新生成一套工程。尚未建立远程仓库，也未对外发布。
