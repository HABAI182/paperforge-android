# PaperForge界面组织

本轮目标是减少同屏入口与重复导航，保留全部工具能力，优先让文档可读、分类可找、操作可返回。保留指定绿色叠纸图标和PaperForge名称。

## 布局参考

2026-10-29阅读以下官方页面，借鉴信息组织方式，不导入竞品图标或页面资产：

| 参考 | 官方页面中的做法 | 本轮采用 |
|---|---|---|
| Files by Google | 分类浏览、收藏集合、单项菜单与多选 | 文档收藏入口固定，工具菜单统一常用固定与能力说明，多选继续保留 |
| Apple Notes | 文件夹/子文件夹、列表或画廊、搜索，排序等操作放进更多菜单 | 文档保留列表/封面偏好，筛选和布局按需展开；内容画布优先 |
| Readwise Reader | 少量文档集合，并可根据工作流选择更简单的组织方式 | 文档默认只显示最近/全部/收藏，任务与自动化另放一个工作台分类 |

来源：[Files收藏与多选](https://support.google.com/files/answer/10317313?hl=en)、[Apple Notes官方操作与页面图](https://support.apple.com/en-us/118442)、[Reader集合配置与页面图](https://docs.readwise.io/reader/guides/workflows/library-configuration)。这些是设计参考；PaperForge的具体结构为本项目决策。

## 最终页面层级

文档、工作台、设置三个主目的地，不再同时摆出首页、文档、转换、工具等重叠入口。文档页只有一个扫描主按钮；回收站始终在文档顶栏，详细条件折叠。最近阅读独立一张卡片，回到原页码。

工作台根页面展示搜索、最多四个常用快捷工具和六个分类。分类内以统一行卡展示工具；格式转换再按Office、表格、电子书、图像、文本等格式族组织。搜索跨分类查找，进入工具后返回原分类。次要功能放进一个菜单，避免每行堆叠星标与信息按钮。

设置首页顶部显示指定标志、版本、检查更新和GitHub。六个偏好板块分别进入；详细设置的搜索覆盖所有板块。导入/导出设置和恢复默认收在高级设置，隐私开关集中到隐私与安全。更新页集中更新任务，去掉重复的传输/智能入口。

统一圆角、表面颜色、图标色、标题与说明的层级。普通字号双列分类，窄屏/大字号用紧凑横向卡片，选项可换行；保留已有主题、字号、封面密度与快捷顺序。默认不启用远程任务、局域网服务或定时更新。

## 验证范围

只验证本轮导航、分类、搜索、设置、分享和更新入口，保留实际截图与版本记录。未改动的原生扫描/Office/格式算法不重复全量测试；历史结果与本轮UI证据分开标记。设备实拍、完整TalkBack和实体折叠机的剩余范围仍见版本状态文档。


## 1.0.1继续整理

阅读底栏精简为视图/页面/批注/工具，次要阅读操作归入阅读分类；格式转换、PDF工具和设置继续使用两列用途卡片。工具箱预设四个常用功能，文档页也直接显示视图入口。

主题提供跟随系统、明亮、深色、纯黑、暖纸和午夜蓝，另有八种主题色。跟随系统只跟随明暗；共享theme-core统一背景、卡片和联网页面颜色。固定纸感/午夜主题不叠加壁纸动态色。

检查更新只查询并显示明确结果，由用户决定下载；没有适配安装包时不显示“已是最新版本”。项目首页和安装文档围绕公开下载与常见入口组织，详细研发历史保留在对应记录中。
