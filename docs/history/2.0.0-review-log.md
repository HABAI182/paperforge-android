# 2.0.0 审核修订记录（开发过程，未单独发布）


- 审核修订 20011：扫描快门与模式居中，取景区增加最近单页预览/修改，左下提供撤回与重拍；撤回会先取消该页后台拍摄任务，保留原片与历史恢复。预览可进入既有 AI 高清，生成独立副本。
- 四边细化增加持续材料证据，排除同纸明暗横线的误裁；白底清理使用局部墨迹锚点并保护斜向淡笔画，SR 避免把纯白纸重新染灰。实图清洁收益有限，激进阈值与新模型校准未通过内容保留要求，未接入默认。卡片展开/收回提前取源帧并平滑衔接小端，保留父页静止及单一实际页面树。实现、实图、不利结果及未达标项见 [20011 记录](docs/quality/CAMERA-PAPER-2026-11-03.md)。

- 审核修订 20010：暖纸上的肤色按纸色比例判断，强种子经弱肤色连通到边缘再精修；保留已接受的原种子，避免暗手部只清掉亮芯。小范围 GrabCut 排除不连接手部的铅笔，手旁中性投影按照明场修正，保持可见笔画。
- 练习册在归一化纸面对比度中混合强度，减少灰黄纸底回混；横线保护先要求连续方向支撑，避免把密集透印保护成横线。笔画增益降为 1.15，原图仍只裁切、不调色；已有带版本的旧增强从保留原片和网格重放，缺少原片的旧结果继续保留。
- 卡片退出反向收回，返回父页保留视口并取消多余横向位移；扫描入口使用同套展开动效，工作台与设置去除多余底部滚动空区。布局、配色与对称卡片保持。
- 两张新原照片经过实际 Android 检测、几何与自动外观多轮对比，拒绝损失铅笔的过强阈值和使字变粗的增益。剩余灰色透印、细轮廓及 3 秒预算差距明确记录，见 [20010 实图与动效记录](docs/quality/PAPER-MOTION-2026-11-03.md)。不创建 PR、tag 或 Release。

- 审核修订 20009：原图回到保留的未调色裁后像素，旧增强外观归为练习册，默认练习册；显示滤镜收拢为原图、练习册、强力去背景、灰度，保留旧滤镜数据兼容。
- 边缘手部使用已有 OpenCV 的小范围 GrabCut 精修，强力去背景采用独立背景阈值；源笔画与淡字保护保留。泛白斑块清理实验无实质收益，未采用，仍不宣称完全去透印。
- 几何使用分析图估计、成片从原色采样，保留后续手部清理线索；零强度网格保持实际恒等，避免滤镜切换时四边拉伸。
- 一键扁平化改用快速自动成片路径，明确直接更新该页，后台完成不打断其它文档；结果可撤销，任务中心可重新打开。栏目入口改为从点击位置展开，主界面布局和配色保持。
- OCR 修复后续识别找回整行却被合并逻辑丢弃的问题，统一识别几何与导出页，增加可逆光照视图、合适采样高度的行块补识；参考 PaddleOCR、Tesseract、OpenCV 官方资料。新增自动选择已安装匹配模型及无模型离线回退，保留手动引擎选择。质量、时间与范围见 [本批证据](docs/quality/OCR-WORKBOOK-2026-11-03.md)。

- 审核修订 20008：单个底栏选中块连续跟随，途中缩小再恢复；页面衔接放缓并略增位移，保持现有对称布局。
- 练习册降低笔画增益，确定空白不再混回灰底；加强边缘手部、投影和多层纸边处理，复用文字曲线校正印刷页。自动轻量 AI 默认开启，按设备耗时调整工作尺寸；保留原片与手动完整模型。实际结果、冷启动预算差距及未解决的灰痕见 [本批审核](docs/quality/BOOK-MOTION-2026-11-03.md)。
