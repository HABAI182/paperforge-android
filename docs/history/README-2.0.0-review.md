# PaperForge

手机本地的扫描、PDF阅读与文件转换工作台。个人非营利项目，无账户、广告、水印或订阅。

**2.0.0 · 待机主审核的完整功能候选版（未发布）**，Android 8.0及以上，普通64位ARM手机只需安装一个APK。Office、特殊格式和联网工具均已内置，日常文档处理无需电脑。

本轮聚焦练习册图像处理，保持现有页面和对称布局：横线、竖框和可靠文字行共同约束几何；增强先保护连通笔画、淡字、标点、表格和彩色批注，再抑制透印。裁剪与手动小角度旋转合并处理，扫描、预览、修复和 PDF 图像增强共享内容保护。原片、撤销、旧模型和旧算法开发回退均保留。强档无法区分淡字与透印时自动采用保守处理，仍可能留下灰痕。实现、逐项许可核查和验收限制见 [练习册改进记录](docs/research/workbook-intelligence-implementation.md)。

本批另接入 V7 根页面跟手横滑：拖动即可看到真实邻页，底栏保持固定；点击底栏保留原有过渡，最近/全部仍即时筛选。按钮、卡片、配色与对称布局保持原样，详见 [动效验证记录](docs/quality/MOTION-V7-2026-11-02.md)。滤镜编辑从保留原片回放已有校正网格，避免重复增强已处理像素。

11 月 3 日针对机主拒绝的实图继续修复：页眉随可靠横线平移，保护完整软笔画；在几何处理前清理受限的纸外暗角和宽块边缘遮挡。练习册常用导出画质改为无损页图，明确选择低于 80 的省空间画质仍用 JPEG。8 张实图、50 次循环与定向检查已执行，顶部纸边、部分灰痕和遮挡处的横线端点仍有差距，尚未通过实体手机验收；完整证据和不利指标见 [本批审核](docs/quality/WORKBOOK-REVIEW-2026-11-03.md)。

当前审核修订 **20011**：扫描快门与模式居中，增加最近单页预览、修改、撤回和重拍，AI 高清生成独立副本。四边细化增加材料证据，白底清理收紧连通分量的保护范围并保留斜向淡笔画，SR 保护纯白纸面；卡片展开/收回提前获取源帧并平滑衔接小端。保持既有对称布局。实图清洁仅小幅改善，灰色透印、纸边和 3 秒目标仍未达标，见 [20011 审核记录](docs/quality/CAMERA-PAPER-2026-11-03.md)。暖纸手部、投影与返回视口见 [20010](docs/quality/PAPER-MOTION-2026-11-03.md)，OCR 自动路由、补行与离线回退见 [20009](docs/quality/OCR-WORKBOOK-2026-11-03.md)。原片及全部已有模型保留，此版仅供本机审核。

## 下载与更新

2.0.0 仅交付机主审核包，审核通过后才创建正式标签和 Release。当前公开版本请从[发布页](https://github.com/HABAI182/paperforge-android/releases/latest)下载；请以发布页实际附件版本为准。只安装这个APK；`release-manifest.json`和`SHA256SUMS.txt`是核对文件，源码压缩包也不是安装包。沿用原应用身份和证书，可覆盖更新并保留文档。

手机内进入**设置 → 检查更新**，会明确显示最新版本、发现更新或连接失败。发现新版后由你选择下载，核对完成再交给Android系统安装器确认。自动更新默认关闭，可开启每日检查及 Wi-Fi 自动下载；安装始终由系统确认。公开仓库无需GitHub令牌；自定义私有仓库可在更新页配置只读凭据。

## 三个主页面

| 页面 | 内容 |
|---|---|
| 文档 | 最近、全部、收藏、搜索、导入、扫描、多选和回收站；顶栏“视图”切换列表/封面 |
| 工作台 | 扫描与识字、格式转换、PDF工具、文档整理、任务与流程、连接与智能 |
| 设置 | 检查更新、外观、拍摄、识字、导出、高级和隐私偏好；使用说明下方为项目主页 |

转换和PDF工具继续按用途分成第二层卡片，避免把所有功能铺成一张长清单。工具可以固定到常用，默认预设去水印、识字、转图片和转Word。

已保留的整理功能：文档卡片直接显示分类并可移入文件夹，多选支持一并移动，创建文件夹时可选择已有文档；扫描使用系统照片选择器，默认练习册并显示滤镜处理状态，高清与修复自动预览。扫描底部支持滑动切换文档、原色、去透页和证件模式，编辑器“更多”改为用途卡片。外部分享 PDF 先打开文档，“处理后分享”由用户主动选择。具体实现、同图对照及未验证范围见 [真机反馈补强记录](docs/quality/FEEDBACK-2026-11-01.md)。

打开PDF后，底栏只保留**视图、页面、批注、工具**。左右翻页、连续滚动、全屏、适页/适宽与纸张颜色集中在“视图”；目录、书签、朗读、翻译等放入阅读工具分类。双击/双指放大后可拖动检查细节。

## 主要能力

- **扫描与识字**：自动识边、连续拍摄、裁边精修、增强、去阴影、彩色/灰度/黑白；离线OCR、可搜索PDF、原图与处理历史。
- **阅读与整理**：翻页、滚动、缩放、全屏、书签、搜索、原页选字、重排与离线朗读；文件夹、标签、收藏、多选、直接删除及回收站。
- **PDF工具**：合并、拆分、抽页、旋转、裁边、拼版、水印、页码、批注、表单、密码、脱敏、证书、归档检查、压缩和资源优化。
- **文件转换**：手机本机Office排版；PDF/图片/Word/Excel/PowerPoint/文本/Markdown/HTML/EPUB等转换；表格与文档结构重建、特殊格式和逐页图片输出。具体输入、输出与限制在每个工具的能力说明中列出。
- **任务与流程**：批量转换、配方、自动导出、结果记录、失败重试和断点复用；完整备份/追加恢复。
- **连接与智能**：局域网直接浏览应用文档库、分类搜索/封面/多选下载、配对互传与断点保留、按需下载语言包的本机翻译，以及自定义局域网/BYOK服务。自动更新需主动开启；其它联网任务由用户发起，原文按页码或选区选择。

## 外观与默认设置

六种外观：跟随系统、明亮、深色、纯黑、暖纸、午夜蓝；八种主题色：墨绿、海蓝、鸢紫、琥珀、青碧、玫瑰、岩灰、咖啡。跟随系统同步明暗，主题色独立选择；更新、传输和智能页面使用相同配色。窄屏与大字号自动调整卡片排列。

扫描PDF默认不做OCR，默认多页扫描、练习册滤镜，证件不套滤镜；默认自动拍摄、85%增强、原比例纸张、标准清晰度与86%导出图片质量；相机 JPEG 94%，自动成片长边 1400px，按耗时适应到最低 1200px；默认开启轻量 AI 精修，完整模型可从高清修复手动运行。改名保留输入名称，真实重名才处理冲突。升级本候选版时将拍摄方式迁为多页，之后保留手动选择；本次升级开启自动轻量 AI 精修，原 97/90 的相机/导出质量迁为 94/86，其它自定义质量保留；已有文档滤镜不变，空的常用工具列表补入预设。

## 本机开发

JDK17、SDK36、Build Tools35.0.0、NDK28.2.13676358、CMake3.22.1；使用仓库中的Gradle Wrapper。先准备固定来源的手机Office运行时，再构建隔离调试包：

```text
python tools/fetch_office_runtime.py --abi arm64-v8a
./gradlew :full-app:assembleDebug -PpaperforgeAbis=arm64-v8a -PpaperforgeIdSuffix=.local
```

Windows将`./gradlew`换成`.\gradlew.bat`。调试APK位于`full-app/build/outputs/apk/debug/`，使用自己的调试证书与`.local`身份，不覆盖所有者发行包。正式包需要仓库外的所有者签名配置；构建/核对流程见[分发说明](docs/development/DISTRIBUTION.md)。

`app`及独立Office/格式/联网模块保留，便于开发和历史模块化构建；普通使用者下载完整功能包即可。共享主题在`theme-core`中，避免不同页面颜色不一致。
