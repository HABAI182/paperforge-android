## 本轮实现

| 反馈 | 实现与主要文件 |
|---|---|
| 分类不方便 | `MoveDocumentsDialog.kt` 提供可搜索的目标卡片和新建并移入；`HomeScreen.kt` 单文件分类标记与多选栏直接可达；取消移动保留原多选；`LibraryFolderDialog.kt` 创建时可搜索并勾选已有文件；`MainViewModel.kt` 复用分类、文件夹持久化、事务及撤销。分类显示在标题下，离开文档库时收起分类提示。 |
| 相册打开文件管理器 | `MainActivity.kt` 使用 AndroidX 系统照片选择器，多选图片进入既有导入管线；旧系统按系统提供的回退入口工作。 |
| 纸边带入桌面 | `NeuralEdgeDetector.kt` 先拟合模型厚边的脊线中心，再沿用原高分辨率精修；`PageDecoder.kt` 默认精确渲染可见四角，`scan_params.json` 的 `cropSafetyMargin=0`，手动扩框保留。已有边界/曲面模型不替换。 |
| 默认与相近滤镜 | `SettingKeys.kt` / `UserSettings.kt` 将扫描默认值迁为练习册；可见列表保留原图、练习册、自然、强力去背景、灰度、柔和黑白。TEXT、COLOR、WHITEBOARD 的旧文档解码继续保留。 |
| 背面透字、下一页模糊内容 | `EnhancePipeline.kt` 练习册与强力去背景共用局部纸面估计、平滑笔画证据和低墨色清理；两者用不同参数。练习册最终 gamma=1.7，多保留失焦淡字；强力去背景 gamma=2.2、去透页更强。两者都可调“淡字保留”，最大值弱化灰痕抑制。 |
| 高清与修复实时预览 | `ScanRetouchScreen.kt` 300 ms 合并连续输入，取消过期计算并丢弃旧结果；整页与涂抹选区均自动预览，显示处理状态，沿用原图比较、全屏和持久任务另存。 |
| 滤镜像失效 | `EditorScreen.kt` / `ScanPageCanvas.kt` 保留已显示的画面直到新结果到达，同时显示“正在应用…”；取消的渲染不覆盖最新选择。 |
| 更多菜单繁杂 | `EditorMoreSheet.kt` 复用 `SectionCardGrid`，分为识别与文字、页面编排、画面与修复、导出与票据、智能工具、文档与记录。深色背景与分类卡片区分。 |
| 收到分享后直接另存 | `MainActivity.kt` 收到 PDF 后导入并打开 PDF 文档界面，不自动处理；`ReaderScreen.kt` 的“处理后分享”移到导出工具，主动使用既有保存/分享管线，设置同步解释新行为。 |
| 每个工具缺说明 | `ToolDescriptions.kt`、`WorkspaceComponents.kt`、`ToolCapabilityDialog.kt` 为工具菜单提供能力、输入输出、参数和处理方式；扫描更多子项有说明按钮，底部操作可长按查看说明，原有加页长按菜单保留。 |
| 常用扫描方式切换 | `ScanCaptureModes.kt` 使用可滑动、居中吸附的模式栏，支持文档、原色、去透页、证件和黑白；实际更新冻结拍摄配方的滤镜与比例，单页/多页对应拍后检查偏好。 |
| 切换缺少灵动感 | `DocumentWorkspace.kt` 对同一内容树使用阻尼弹簧位移、轻微缩放与透明度进入；保留减少动效偏好，不复制后台相机或 OCR 副作用。 |

## 图像观察与参数选择

P1–P4 是四张新增机主照片，P5–P7 只用于观察扫描界面布局。新增照片与此前三张机主照片共七张，均运行真实 Kotlin/OpenCV/MNN 链路。先以原参数（无脊线精修、1% 渲染外扩、旧练习册及旧 CLEAN 分支）建立对照，再输出本轮版本。只改练习册墨色曲线时复用已测四角和未滤镜的裁切图，避免反复检测及重做基线。

已逐张查看旧练习册/新练习册/旧强力去背景/新强力去背景联系表，并放大新增照片的字迹区域。强力去背景在这些照片上显著减轻原先残留的灰底、阴影与透页；练习册选择较柔和的墨色曲线，避免只追求纸白造成淡字进一步丢失。曲线 2.8 → 2.2 → 1.7 的比较显示，1.7 更能保留新增第 2、3 张的模糊正面字迹，但这些区域仍未恢复到清晰原件水平。

不能将“变白”当作文字质量提高。全页白像素/墨色比例仅描述输出分布，不等于 OCR 正确率或前景保留率。新照片没有参考 App 同图输出或清晰真值，不报告等价质量、精确角误差或“全部透字已消失”。强去透页与极淡/失焦正面笔迹仍有取舍；很淡的纸张可提高淡字保留或选自然。弯曲纸边的四角透视也不能冒充任意曲面完整还原。

数字摘要见 [七张照片指标](../acceptance/issues/recovery-1.2.0/feedback-review-metrics.json) 与 [滤镜已知掩膜指标](../acceptance/issues/recovery-1.2.0/feedback-filter-metrics.json)。私人联系表、局部放大图、原图与界面截图位于仓库外 `work/feedback-20261101/`，不提交到公开仓库。联系表 new-4 为便于阅读统一旋转，实际导出仍保留源方向。
