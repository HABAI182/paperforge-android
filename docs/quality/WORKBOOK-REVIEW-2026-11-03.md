版本 2.0.0 / 20007，完整 ARM64 审核包。只在本地提交、构建并交付机主，不创建 PR、tag 或 Release。界面外观、按钮文字、配色和对称布局不改；根页面手势另见 [V7 记录](MOTION-V7-2026-11-02.md)。机主已取消定时续跑和完成后关机。

## 修复的具体问题

机主拒绝的拼图是同一张原片的处理结果。原片 `8b058fd55f427536d975b61df77d3ca4.jpg` 为 1279×1706，旧裁后图为 916×1186；参考 App 内嵌 JPEG 为 2240×3164。三者均保留在仓库外，原片不覆盖。不能把参考输出更大的像素数当成已恢复的光学细节。

| 位置 / 问题 | 实际修改 |
|---|---|
| 顶部公式发虚、被挤压 | `RuledPageRefinement.kt` 对无横线支持的页眉/页脚采用最近可靠横线的平移，统一缩放保留整个原图，避免将公式挤在固定的外边界上；只在可靠横线之间限制网格导数。`InkComponents.kt` 和原生 `paper_pixels.cpp` 使用两个对比度层级的连通域，从完整软笔画取得正面支持，再做连续、有限的对比度增强；不重写字符 |
| 右手、纸外背景、左下暗角 | 新 `WorkbookPaperBoundary.kt` 分开分析宽块暖色边缘遮挡、暗色纸外区域与展平补白，避免横线把整块外部区域连成一个被否决的组件；要求靠边、限定外带并保留细批注、饱和彩色标注、内部图形和单边实心图形。弱边缘只从已接受区域生长，原图仍保留 |
| 展平后黑框、纸色断层 | 纸外遮罩先于几何处理，背景亮度估计使用延伸的低频纸面场；仅修复背景场，不能生成遮挡下的文字。最终增强后重新清白已确认的纸外区域，防止它被对比度或源图保护重新压黑。`FlatDocument.kt` / `DewarpTrace.kt` 共用这条路线 |
| 编辑滤镜累积、导出与预览不一致 | `ScanProcessor.kt` 用保留的原片和不可变网格重放外观，不重新估计网格，不再对已增强的结果反复套滤镜；保留原始结果、撤销、裁剪和旋转 |
| PDF 再次损失细字 | `PdfImageEncoder.kt` 在练习册常用画质下使用 8 位无损 Flate；灰度页单通道，彩色批注保留 RGB，没有全白软蒙版。`PdfEngine.kt` 识别已烘焙为 ORIGINAL 的展平练习册。低于 80 的明确省空间选择继续用 JPEG。`ScanPageStages.kt` / `ExportWorker.kt` 更新阶段与任务缓存签名 |

`scan_params.json` 提供可扫参的有界参数、细节保留和回退。没有增加模型、训练、运行库或云调用。透印分类仍是源图、连通性、规则线和现有模型的证据组合，不是经过真实逐像素标注验证的语义分割。

## 保留的实验与失败

- 早期只放宽前景增益上限，不能让低置信候选真正增强软公式；改为有完整笔画证据才取得连续的正向增益。淡字、点状符号和未知内容仍有源对比度下限。
- 将各种外部候选合为一张连通图，横线会把背景连接到页内，导致漏删；因此分开求组件。
- 用全局或逐行固定纸色填充补边，在不同光照下形成了新的暗带。现版延伸局部低频亮度场，并在最后重用纸外遮罩。失败 PNG、拼图和日志均保留。
- 现有 MNN 细节模型在这张公式上的额外收益较小；一次模拟器实验（含源图保护）约 1.67 秒。保留可选能力，没有改为默认叠加。
- 现有 CURRENT 学习式曲面网格加横线修正的实验在首条横线中部出现了凹陷；本次约 5.95 秒的记录含增强，不能当成模型单次推理速度。没有据此强制替换新的结构路线。
- 现有 ESPCN 的页眉 3 倍实验约 447 毫秒，视觉收益有限。它不是新拍摄的高清原片，也没有据此声称恢复出所有真实字符。

这些时间来自有顺序、有缓存的模拟器实验，预处理版本也有变化，不是同条件真机性能排行榜。最终默认路径没有启用这些额外推理。

## 验证与证据范围

定向场景覆盖：页眉导数与完整源边界、靠边淡字/标点/彩色批注/实心图形、补白不变黑、机主失败实图阶段、滤镜反复编辑及 PDF 内嵌图一致性、默认练习册 PDF 与明确省空间 JPEG、原有淡字/拓扑场景。V7 检查覆盖按住拖动、取消、反向、落定、同目标重复点击、输入手势归属及拖动期间新底栏意图。

真实照片没有正面字迹 / 反面字迹像素真值、OCR 人工转录或人工角点坐标。SIFT 对齐、墨迹 IoU、参考空白残墨与横线曲率都是诊断代理，不等于真实文字召回率。新旧几何不同时独立配准会引入变化，不能选择性只公布有利指标。原始失败图必须与修复图一起查看。

报告脚本 `scripts/workbook_counterexample_report.py`、`scripts/workbook_intelligence_report.py` 只读取 Android 实际输出，不用 Python 增强结果替代应用结果。私有证据目录为工作区外的 `work/workbook-counterexample-20261103` 与 `work/workbook-intelligence-20261102`。最终执行日志、指标、PDF 和 APK 清单随本地审核资料交付；未实施真机拍摄 / 真机帧率验收。

### 不利指标与视觉差距

同一新几何下比较旧外观与新内容保护，三个带参考的旧照片结果如下；对齐和空白掩码均只是诊断代理。

| 样本 | 参考空白中深残墨比例，旧 → 新 | 空白平均残墨，旧 → 新 | 墨迹 IoU，旧 → 新 |
|---|---|---|---|
| old-1 | 0.02478 → 0.02269 | 3.48894 → 5.05558 | 0.16474 → 0.13543 |
| old-2 | 0.00630 → 0.00440 | 0.82049 → 1.72859 | 0.33691 → 0.33597 |
| old-3 | 0 → 0 | 0.00901 → 0.80080 | 0.18209 → 0.16557 |

深色残留有所减少，但保留不确定灰色内容使平均残墨上升，IoU 也未全面改善，不能宣布去透印已经达到参考。机主失败图另行对齐的完整原片结果，IoU 从拒绝图 0.34811 到 0.35706，参考横线追踪 P95 从 5.900 到 4.171px；新旧几何分别配准，**不能与上表当作同一实验或文字准确率**。

实际逐区查看的结论：公式对比度比被拒绝版本更完整，手部色块和左下暗角明显减轻；顶端仍有细小纸外碎片，去手处的横线端点不齐，部分灰痕和纸面纹理仍在，页面观感未达到参考。被手真正遮挡的内容没有可恢复源像素，本版没有生成或补造字符与横线。

## 仍需机主检查

1. 顶部极小公式的真实可读性、页边批注和淡铅笔，特别是贴边或与阴影交叠的内容。
2. 严重曲面、真正被手遮挡的内容和较强反页印刷；单张照片不能证明所有灰痕都是无用背景，本版继续保留不确定内容。
3. 参考页比例与原纸比例不同。没有为了拼图相似而将每种纸强行拉伸成 A4；已有显式纸张比例仍可使用。
4. 真实手机上的预览、批量处理时间和内存；模拟器处理真实照片不等于实体手机验收。

没有宣布 100% 复现参考 App。下一轮若需要更强语义分离，应先补足经授权的真实前景 / 透印标注与独立验证集，再按任务书评估轻量模型；双面配准需要实际正反配对，不能由单面照片假造。
