# PaperForge 1.0.0 收尾状态

本页为历史记录；当前版本见[1.0.1](V1.0.1-STATUS.md)。

版本为 **1.0.0**，完整功能单APK版本码10003（原四包候选为10000），沿用原主应用身份和证书，可覆盖安装并保留文档。主应用显示名为PaperForge，图标来自所有者提供的绿色叠纸原图。

所有者在认可已说明范围后，明确要求将功能整合为单APK并发布1.0.0，故本次解除`releaseHold`。原有6张设备/质量卡与国际化等工程建议仍按实际状态保留；发布不代表这些项目已全部完成。

## 本次收尾包含什么

- 原生PDF改字按页保存可复用补丁，压缩保存质量候选和JPEG阶段；任务恢复复用已完成内容，最终容器仍原子重建。
- 重后台流程限1，可指定等待任务下一项优先；前台识字优先，调用线程后台调度后恢复。图像预算在排队时冻结、手动重试时更新，覆盖PDF重编码、栅格页、图片包和长图缓冲。
- 58项类型设置集中默认值、范围与枚举，修复JSON恢复遗漏的开关和竖排顺序；保留旧设置兼容。
- 分隔折痕不再横穿阅读内容：竖铰链、横向桌面状态、零宽折痕按窗口坐标避让。同一阅读内容树在展开后保留第2页。
- 脱敏页本地查找邮箱、手机号、身份证格式及银行卡格式候选；优先原生文字、必要时使用手机离线OCR。候选点选后返回预览，可调整范围并显式生成副本。
- 之前已合入的新功能：配对/断点局域网传送、手动下载语言包后的离线翻译、冻结原文并保留页引用的问答、可选更新检查。模块化版主应用保持离线权限；完整功能版内置联网工具并声明网络权限，联网行为按需使用。

## 界面整理修订

10003将主导航收敛为文档、工作台、设置，工具按六类进入；导入、回收站和多选保留。文档详细筛选折叠，设置按六个主题分别展开，仍可跨主题搜索。工作台保留工具目录全部功能，转换中心也按格式分组，并将星标/能力说明收进单个菜单。普通字号双列，大字号与窄屏改为紧凑横向分类卡片。存储、工作流、批量转换和自动导出按来源返回。

新增系统分享入口继续保留完整包的单桌面图标。设置顶部可一键更新或打开GitHub，更新页集中检查、下载与安装确认；新装默认正式版渠道，现有设置保留。UI与分享入口证据单独记在[ui-organization](../acceptance/next/ui-organization/)，既有10001原生转换证据保持原版本标记，不把历史检查冒充本次重测。界面参考与落地决策见[UI组织](../design/UI-ORGANIZATION.md)。

逐项证据见[当前验收目录](../acceptance/next/)，功能状态见[98张任务卡](../roadmap/implementation-status.json)。不重复重跑已通过且本批未受影响的OCR、格式转换及长文档套件。

## 安装与更新约定

普通手机安装arm64-v8a完整功能APK即可，Office、特殊格式和联网工具已内置，无需另装扩展。无需电脑参与日常文档处理。候选目录的`release-manifest.json`记录源提交、签名、ABI、权限、16KiB对齐与每包SHA256；安装包必须以实际清单为准，不沿用早期候选的哈希。

主应用默认扫描PDF导出不识字；显式OCR仍可从识字/导出选项开启。改名后的显示名称与导出基础文件名保留用户输入，同目录真实重名时才做冲突处理。

对格式匹配的敏感信息提示需人工核对；身份证候选不验证身份，银行卡候选不验证账户。语义删除的限定适用范围与整份栅格副本的取舍在界面中给出。
