# PaperForge 1.0.0 收尾状态

目标版本按所有者最新要求统一为 **1.0.0**，版本码10000。主应用和Office、格式、联网三个可选包从同一份Gradle属性取版本，沿用现有证书；不卸载、不清空原有文档。主应用显示名为PaperForge，图标来自所有者提供的绿色叠纸原图。

目前安装产物仍是候选，`releaseHold=true`。版本名称不代表已完成全部设备与质量验收；收尾前不创建tag或Release。已发布基线仍是0.6.0。

## 本次收尾包含什么

- 原生PDF改字按页保存可复用补丁，压缩保存质量候选和JPEG阶段；任务恢复复用已完成内容，最终容器仍原子重建。
- 重后台流程限1，可指定等待任务下一项优先；前台识字优先，调用线程后台调度后恢复。图像预算在排队时冻结、手动重试时更新，覆盖PDF重编码、栅格页、图片包和长图缓冲。
- 58项类型设置集中默认值、范围与枚举，修复JSON恢复遗漏的开关和竖排顺序；保留旧设置兼容。
- 分隔折痕不再横穿阅读内容：竖铰链、横向桌面状态、零宽折痕按窗口坐标避让。同一阅读内容树在展开后保留第2页。
- 脱敏页本地查找邮箱、手机号、身份证格式及银行卡格式候选；优先原生文字、必要时使用手机离线OCR。候选点选后返回预览，可调整范围并显式生成副本。
- 之前已合入的新功能：配对/断点局域网传送、手动下载语言包后的离线翻译、冻结原文并保留页引用的问答、可选更新检查；联网能力在独立包中，主应用保持离线权限约定。

逐项证据见[当前验收目录](../acceptance/next/)，功能状态见[98张任务卡](../roadmap/implementation-status.json)。不重复重跑已通过且本批未受影响的OCR、格式转换及长文档套件。

## Claude补充建议的工程状态

视觉规范、真实文档封面、手动清理修复、第二OCR引擎、原页选择/重排/朗读、表单证书、敏感信息候选与类型设置已接入。公开真实照片证据与合成小样始终分开。

完整国际化与逐功能ViewModel继续拆分尚未全部完成；类型设置保留兼容的SharedPreferences存储，尚未整体切换DataStore。CI目前执行隔离身份的安装包编译、原生构建和可选引擎编译，不将其写成每次push都通过全量设备测试或全量lint。上述工程建议不因98张卡的计数而自动完成。

## 安装与更新约定

普通手机使用arm64-v8a主APK。需要Office排版、特殊格式或联网扩展时安装同一批、同一签名的可选包。无需电脑参与日常文档处理。候选目录的`release-manifest.json`记录源提交、签名、ABI、权限、16KiB对齐与每包SHA256；安装包必须以实际清单为准，不沿用早期候选的哈希。

主应用默认扫描PDF导出不识字；显式OCR仍可从识字/导出选项开启。改名后的显示名称与导出基础文件名保留用户输入，同目录真实重名时才做冲突处理。

对格式匹配的敏感信息提示需人工核对；身份证候选不验证身份，银行卡候选不验证账户。语义删除的限定适用范围与整份栅格副本的取舍在界面中给出。
