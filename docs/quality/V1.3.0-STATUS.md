# PaperForge 1.3.0

完整 ARM64 单 APK，内置 Office、格式转换与联网引擎。本版在 1.2.0 内容（#22 练习册增强、#21 满幅伪检测修复与拍后质检、#7 量化基准）之上，新增 #28「分享即处理」。

## 分享即处理（#28）

- 在扫描 App 里分享 PDF 给 PaperForge，直接走「读取 → 去水印（可关）→ 压缩（可关）→ 转发」，原件不进入文档库。
- 去水印是通用对象处理：重复出现的小图水印按对象移除，角落文字水印遮盖；不内置任何第三方品牌特征。
- 转发优先指定微信包名（`com.tencent.mm`），不可用时退回系统分享面板。**微信不支持静默发送，最后一步必须用户点发送。**
- 设置 → 导出与文件名：分享处理、去水印、压缩与转发目标四项开关。
- 已知限制：文字层中的水印文字仍可被选中（视觉遮盖，未改写内容流）；仅处理 PDF，图片分享仍按导入处理。

## 验证范围与缺口

- 去水印与分享流水线在**真实扫描全能王导出样本**上验证：三份样本共 10 页，图片与文字水印全部移除，非水印区域像素差 0；分享流水线压缩后 509,226 → 207,011 字节。
- 环境为 API35 x86_64 模拟器；真机、真实拍照质量与夸克扫描王样本未测。
- 既有 `EditorExperienceTest` 在本机 AVD 于裁切画布手势处注入失败，`main` 同样复现，非本版引入。
- 裁边/透视算法本体仍待改进（当前只修复了满幅伪检测）；真实样张的淡字/铅笔/反光对照仍未提供。
