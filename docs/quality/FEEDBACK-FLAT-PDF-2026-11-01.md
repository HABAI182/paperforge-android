## 来源与复现

DocRes 是 [CVPR 2024 作者仓库](https://github.com/ZZZHANG-jx/DocRes) 的公开实现，MIT；Restormer 许可一并随包。权重来自作者 README 链接的公开演示空间，固定 revision `e9d734906ea26ec569a8daeac0bfd14f495990ab`，原检查点 SHA256 `1d6a89d754fe1e58ffd1865eab0ef3f03344798d39197b2d9a77ce4fbc8c02fd`。原 Python appearance prompt 的 BGR、1024 纸面场和高分辨率比例传递在 Kotlin/OpenCV 中适配实现。

`scripts/prepare_docres_model.py` 已实际复现随包模型：15,890,584 字节，SHA256 `d11338eb9c5cb67f3c6de192fafe3b050def10465b9b89d7fe47e305dbdcaff9`。它是权重量化、浮点激活，不宣称全 INT8 计算加速。自身照片单个 128px 检查块上，与浮点 ONNX 平均绝对输出差 0.004226、最大 0.036778；这只是该检查块的量化误差，不是完整数据集的精度结论。

原有 border/dewarp/detail 权重与 SHA 均保留。专门比较发现再叠加旧细字模型会提高残墨和边缘振铃，因此新成片默认 `flatDetailStrength=0`，不自动叠加这一步；原有“文字高清”入口和模型保持可用，参数仍可单独扫描。未得到夸克的源码或训练模型；不将相似行为实现表述为复原其完整私有算法。

## 同图核验

最新 P3 左页，沿用一份明确的手动四角标注，对比相同裁剪的旧练习册结果与新结果；P1 去掉应用边框后的页图作为参考。该组用于隔离“展平与增强”质量，不伪装成这张书籍照片的自动裁边误差测试。新的自动拍摄流程另外使用有真实纸框的样张验证。

`scripts/scan_flat_contact.py` 生成三列对照图和度量。900px 分析宽度，SIFT/RANSAC 对齐内容后：

| 指标 | 原练习册 | 新成片 | 参考 |
|---|---:|---:|---:|
| 参考空白区的暗像素比例（亮度 < 210） | 0.5495% | 0.1447% | 参考白区定义 |
| 参考空白区平均残墨（0–255） | 0.6588 | 0.1786 | 参考白区定义 |
| 独立纸纹追踪的中位弯曲 RMS | 2.757px | 1.311px | 0.480px |
| 对齐后的严格二值墨迹 IoU | 0.4153 | 0.3552 | 1 为完全一致 |

前两项降低约 74% / 73%，弯曲 RMS 降低约 52%。严格像素 IoU 没有提高；线宽、灰度、边缘形变和截图采样仍不同，因此不能据此宣称完全相同、OCR 正确率提高或 100% 复现。新成片为 1697×2400。对照图与原图只放入机主本地审核资料，不提交公开 Git。

仍能看到边缘纸纹的残余弯曲、少量灰点和部分细笔画差异。下一项实验应针对边缘曲率和小数/上下标区域做有标注的局部比较，避免用更强的整体阈值换取“看起来更白”。

## 验证范围

已分别通过 8 个针对性场景，不重跑历史 Office/OCR/全套回归：

- 新原图在 Android 运行真实 DocRes、几何、细字与超分，保存 PNG 与可解析的单页 PDF。
- 真正的拍照任务自动发布成片、保留源文件/网格，并能撤销。
- 已有草稿通过真实 WorkManager 展平任务更新原文档，保留名称、网格，并可撤销。
- 旧 PNG/日期命名偏好下，编辑器仍生成“概率论课堂笔记.pdf”；导出不改写源标题；分享与打开 chooser 都携带正确 PDF MIME、名称、读取授权和可读字节。
- 应用文档库作为 PDF、无损逐页 PNG、已有 DOCX 导出文件的输入。
- 裁剪/旋转标签共用草稿，保存角度与微调；编辑器重拍，相机不出现重拍按钮，证件无滤镜、多页默认。
- 最近/全部切换时，暂停动画时钟核对主标题不发生整页位移。
- 实际 HTTPS 配对后的详情、两页预览、下载/范围请求，以及真实浏览器预览弹层、翻页和无横向溢出。

其中工作流 4 项合并运行 78.801 秒通过，恢复原审核包中的同 SHA 私有细字权重后，成片及已有草稿任务两项 58.580 秒通过；默认关闭叠加锐化后只复核该照片成片，41.481 秒通过；其余场景在各自相关修改完成后分别通过。早期脚本曾有搜索框/卡片重复文本与异步预览定位问题，已修正；也实际发现并修复了整帧复用的 1px 缩小问题。早期 256px AI 图在小内存模拟器上被系统杀掉，最终改成 128px 且禁用 CPU arena / 内存模式，在同一模拟器完成；观察到的处理阶段 PSS 约 494MB、RSS 约 583MB，属于采样值而非严格峰值。

离线 AI 较慢：此前完整未缓存模拟器样张约 189 秒，末端处理复用已验证的相同模型输出后约 16–24 秒；这不是实体 ARM 手机性能。最终开启小切片 CPU 权重预打包并保留快速模式开关，实体手机的速度、温度、内存以及微信/QQ/钉钉/WPS 等接收方行为由审核 APK 验收。

发布前仍须机主确认。以上是本批反馈的实现和定向证据，不代表所有历史 Issue、任意失焦原片或所有私有算法已完全复现。
