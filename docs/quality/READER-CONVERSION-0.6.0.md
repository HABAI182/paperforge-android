# 0.6.0：手机本地阅读与转换

默认工作流全程在手机。Office 首次安装一次手机引擎，Word/Excel/PowerPoint/ODF 排版由 LibreOfficeKit 26.2.6.3 完成，结果通过临时 URI 自动返回纸匠。手机表格和结构导出使用已有 PDFBox/OpenCV/离线 OCR，在纸匠中运行。

## 本次验证

- 8 个聚焦 Android 检查覆盖阅读与进度、原有多选删除、基础转换、长图/WebP、手机表格和结构 DOCX/PPTX。
- 手机主应用真实文件选择 → Office 引擎 → PDF 返回流程已实际操作。
- 强停应用并重新打开同文档，阅读页码仍为第2页。
- 原生/扫描表格样例的 `00123`、`120.50` 和 `A1:B1` / `A5:B5` 合并关系正确；无线表和跨页同表头连接也已检查。
- 独立 `openpyxl`、`python-docx`、`python-pptx` 读取了手机生成的文件。Office 源文档、实际手机引擎PDF和结构导出在[验收目录](../acceptance/v060/)中可对照。
- APK 签名、ABI、16KB 对齐、无 INTERNET 权限与最终构建记录另见同目录的包核验文件。

交互设备为 API35 x86_64 模拟器；ARM64 产物仅做构建和包结构核验，不称为实体手机验收。本次未重跑扫描/OCR全量语料和压力测试，未重新声称已经解决所有实拍问题。

## 能力与限制

Office 使用实际排版引擎，仍受字体替代、源文档打印范围与复杂对象影响。PDF→DOCX 重建可编辑文字、表格和嵌入图片，复杂跨栏/裁剪图像/脚注不保证还原。PPTX 为整页图像模式。扫描与无线表存在识别推断，可逐格校正后导出。
