# Local search and optional privacy controls

Room migration4→5 backfills an FTS4 index from existing OCR. CJK unigrams/bigrams and normalized Latin/digit terms are generated locally; page insert/update/delete and document deletion maintain index entries transactionally. Metadata title/tags/folder matching remains. Quoted term-only FTS expressions prevent user input from becoming query operators. Whitespace implicit-AND is used because explicit AND required an optional SQLite compile flag on the AOSP test image.

`SearchIndexTest` passes on real Android SQLite: Chinese multi-character and single-character queries, Latin/digits, operator-like input, OCR changes, trash filtering and deletion. Existing data migrated without clearing the database. Search is token based: English body terms require whole tokens rather than arbitrary substrings; CJK long queries combine bigram evidence and can match terms occurring apart. Exact phrase/proximity ranking remains a refinement.

Existing About/privacy dialog now contains optional screen protection (`FLAG_SECURE`) and an app lock using Android system device credentials. Both default off. Device PIN/password must already be configured; PaperForge stores no password. Initial process entry and returns after>30s background require verification; orientation recreation retains process authorization. Sensitive content/import handling waits behind the lock. The lock controls app access and does not encrypt stored files or exported/shared copies. Screen protection is a separate switch, including recent-task screenshot protection where Android honors the flag.

Android API35 home/privacy UI and reading navigation checks pass after integration. Full device-credential prompt, OEM recents behavior and biometric acceptance were not tested on a physical device; the app does not claim biometric support. References: [Android KeyguardManager](https://developer.android.com/reference/android/app/KeyguardManager), [FLAG_SECURE](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#FLAG_SECURE). Existing PDF encryption and confirmed manual redaction remain. Automatic PII suggestions are deferred; no unreviewed automatic redaction is added.
