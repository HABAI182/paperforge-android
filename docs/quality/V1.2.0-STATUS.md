# PaperForge 1.2.0

完整 ARM64 单 APK，内置 Office、格式转换与联网引擎。

本版包含两项 P0 与一项基准建设：

- **#22 练习册/薄纸增强**：新增「练习册」滤镜，在光照校正后用纸面残差软阈值抑制反面透印与灰底，保留正面细字、铅笔、公式与表格线；默认预设改为易懂口径（原图、自然、清晰文字、练习册、强力去背景、灰度、柔和黑白、彩色、白板），编辑页、设置、PDF 图像增强与离线说明统一。
- **#21 拍摄可靠性**：满幅轮廓不再冒充已定位文档（无文档误检从 62.5% 降到 0，空桌面不再触发自动拍摄门槛）；拍后基于实际原图检查失焦、局部模糊、反光、缺边、过暗/过亮，只给轻量重拍建议，照片照常保存。
- **#7 量化基准**：新增扫描质量基准（裁剪 IoU、角误差、检测率、误裁率、无文档误检率、检测延迟），设备侧跑分 + 桌面复算脚本，后续改动按同一把尺子对照。

详细验证见下列记录：

- [扫描质量基准](../acceptance/scan-quality/README.md)（语料、指标定义、改动前后对照）
- [#21 验收](../acceptance/issues/21/README.md)（满幅伪检测、拍后质检）
- [#22 验收](../acceptance/issues/22/README.md)（练习册去透页、预设改名、合成薄纸指标）

## 验证范围与缺口

- 全部验证在 API35 x86_64 模拟器与**合成样张**上完成；真机、真实拍照质量未复验。
- **真实样张尚未提供**：淡字、铅笔、反光、薄纸透印的真实照片对照仍缺，无法给出真实场景结论。
- 裁边/透视算法本体未改：弱边界、斜拍、遮挡等场景的改进仍待做，本版只修复了满幅伪检测。
- 既有 `EditorExperienceTest` 在本机 AVD 于裁切画布手势处注入失败，`main` 上同样复现，非本版引入；发布前 UI 走查改用截图核验。
- 未做 OCR 前后识别率比对。
