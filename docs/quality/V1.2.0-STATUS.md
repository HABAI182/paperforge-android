## 独立实现试用分支

按行为重实现 brief 新增可选的独立识边和文字行展开，现有模型文件、原生运行时及默认扫描链路保留。新分支仅使用已有 OpenCV / DocQuadNet 与原创文字行拟合，不调用现有私有模型。入口位于设置的纸张定位及曲面校正引擎；默认仍是原引擎。

行为依据、无法从静态输出观察的部分和参数说明见 [行为规格](../research/BEHAVIORAL-SCAN-SPEC.md)。3 张机主照片已与参考 PDF 逐页配对，实际处理图与对照图保留在仓库外，数值摘要写入恢复开发记录。独立分支目前是试用基线，不能宣称已达到参考应用质量。

## 验证

本地另有原尺寸神经“文字高清”试验，已生成三张实际输出，来源、差距与是否随公开源码提供的边界见 [细节恢复记录](../research/DOCUMENT-DETAIL.md)。不替换默认链路，也不将本地审核权重计作已发布或 OSS 能力。

本轮仅编译、针对变更的滤镜/文件夹检查与 APK 身份核对，避免重复全量测试。实际结果和候选文件信息补充在 [恢复开发记录](../acceptance/issues/recovery-1.2.0/README.md)。

最新审核入口：扫描文档 → 滤镜 → 高清与修复 → 练习册高清。普通纸张可单独使用“文字高清”。两者均为显式预览并另存，不覆盖原件。三张真实配对输出及 UI/全屏/保存链路已检查；组合预设相对早期灰底基线改善，但没有在所有代理指标上优于单独文字高清，仍待机主真机审核。具体参数、结果和限制见上述细节恢复记录。

交付构建为单个 1.2.0 完整 ARM64 审核包，代码本地提交后构建。外部 `release-manifest.json` 记录源提交、实际 APK 校验值、证书、ABI、16KiB 对齐及本机审核模型的实际哈希；模型不在 Git 中，不能仅用代码提交重现这一本机输入。不上传仓库或创建正式发布。
