# 2.0.0 / 20006 图像处理补强

**以 本地样本应用 完整版的同图导出效果为基准**，新代码包只作实现参考。只改图像处理、版本和说明；工作台、分类和编辑器 UI 保持上批布局。拍摄反馈、四格导出弹窗和无重叠弹簧过渡保留，[上批记录](CAPTURE-POLISH-2026-11-02.md)为 20005 的实际验证。

## 已接入

读取代码包的增强、修复、几何、基础图像模块及相应说明，移植 `restore.cleanup_faint` 的邻域暗核判据。快速练习册和深度 DocRes 共用以下成片处理：

1. 只筛选灰度 200–251 的浅灰残留。
2. 5×5 邻域有低于 195 的有效暗核时保留，防止擦掉正文抗锯齿边缘。
3. 现有长横线证据或轻量模型前景概率至少 0.85 时独立保留，避免把淡横线和高置信度淡字当成灰雾。
4. 其它候选按当前增强强度趋向纸白；处理强度为 0 或最大淡字保留时，快速模式不执行这一步。

只读取一个固定输出快照判定邻域，不逐像素反馈改写后的结果，避免产生方向性扩散或蚕食笔画。原生循环只对浅灰候选搜局部邻域，没有引入 Python、SciPy 或新增大模型依赖。默认参数与开关全部在 `ScanParams` 可扫的 `scan_params.json` 中。

快速路径在原有连通域去点之后执行。深度路径复用已经生成的灰度和横线/前景平面，连通域统计整批读取，避免每个小点重复 JNI。推理权重与 DocRes 推理缓存未改；成片缓存更新为 flat-paper-5、retouch-8、coherent-ink-5。

## 曲面映射补强

完整版导出对照暴露出某页公式明显拱起。原先纸纹映射有局部过强就整体回退模型，导致数学字迹再次变形。本批 ruled-residual-6 对相邻7条横线的位移做局部 Theil–Sen 稳健回归，使纸面在纵向连续；真实多线共同折痕仍保留，单条分数线不能独自带弯页面。

已有足够纸纹时，对不满足伸缩范围的映射保留受支持的温和部分；极低支持仍回退原有路径。ruledSurfaceCoherence、ruledMapDamping 均可扫参。原模型保留原字节，没有删除功能。

平直公式回归最初仍检测到1.074分析像素的微动，本批增加 flatIdentityTolerance=1.5，这个量级不重采样。最终检查要求成片与平直输入像素完全一致，保留已知真实折痕矫正；没有仅把测试位移容差放宽后宣称通过。

主要文件：`EnhancePipeline.kt`、`InkComponents.kt`、`NeuralPaper.kt`、`PaperPixelEngine.kt`、`paper_pixels.cpp`、`scan_params.json` 与缓存版本。没有改 UI 组件。

## 定向验证与实测

Android35 x86_64，7个不同图像场景有通过记录：灰雾/暗核/横线/置信淡字/零强度、7张原片裁切、P3快速/深度清理消融、完整版三图参数扫描、已知窄折痕与平面、平直公式不产生局部波浪。只有受新改动或失败影响的路径重跑；本批不重跑 UI/Office/备份等历史全套。

七张固定裁切输入中，增强后低于150的暗色笔画像素没有被这一步清理改写；浅灰变化像素比例依次为5.45%、4.85%、0.38%、0.76%、6.10%、0.83%、0.003%。这证明浅灰步骤的暗笔画不变性，不代表所有淡字都已自动正确分类。

P3同图、同几何固定配准下，参考空白区平均残余墨色：快速0.25676→0.25110，深度0.09314→0.09158；二值IoU和暗点比例基本不变。这个改进幅度有限，不能当作已根除深色透印。上述消融在曲面补强前完成，专门隔离灰雾步骤。

### 本地样本应用 完整版参考

从包内实际导出PDF提取3页原始JPEG，逐页目视确认内容和3张原片对应；另用Poppler渲染整页，确认页面结构。参考不使用复刻Python的输出。私人原图/JPEG不提交Git，只保留哈希和指标。

固定旧裁切输入，比较曲面补强关闭/开启（1.0）：

| 样张 | 原路径 → 新路径 | 参考匹配内点 | 二值墨迹IoU |
|---|---|---|---|
| old-1 / 完整版第1页 | 纸纹 → 连续纸纹 | 174→155 | 0.16265→0.17478 |
| old-2 / 完整版第2页 | 模型+纸纹 → 连续纸纹 | 331→588 | 0.17554→0.36399 |
| old-3 / 完整版第3页 | 纸纹 → 连续纸纹 | 53→93 | 0.14673→0.13158 |

最明显的公式拱起在第2页减轻；该次处理记录5.597→2.920秒，但先后运行的缓存/冷启动未受控，不宣传为通用速度提升。更强去背景阈值的预先扫描收益很小且有笔画IoU退步，没有采用严格阈值作为默认。

横线自主追踪RMS（900px）第1–3图为0.384→0.661、0.814→1.192、0.294→0.518；完整版参考分别0.406、0.683、0.275。连续曲面减少公式局部形变，但横线细小残余并非全数改善；第3图IoU退步也保留。各图重新配准，像素指标受非线性几何与参考裁切影响，不能作为逐点真值或把残余都算作噪点。接触表是主验收依据，完整数值见 [指标](../acceptance/next/v200-image/full-app-geometry-metrics.json)。

这些旧裁切固定了输入，隔离图像处理；不是当前自动识边的端到端验收。最终平直公式验证为像素恒等，已知真实窄折痕检查继续通过。
