## 技术与范围

主要修改：`WorkspaceComponents.kt`、`HomeScreen.kt`、`UserSettings.kt`、`PdfToolsDialog.kt`、`EditorMoreSheet.kt`、`DocumentWatermarkScreen.kt`、`DocumentWorkspace.kt`、`SettingsScreen.kt`、`ReaderDisplaySettings.kt`、`ScanExportDialog.kt`、`ScanRetouchScreen.kt`、`NeuralPaper.kt`、`AutomaticUpdates.kt`、`UpdateDownloads.kt`、`UpdatesActivity.kt`，以及版本与分发配置。

去水印沿用上一版实际支持范围：PDF 对象/指定文字、现代 Office/ODF 绘图或背景、旧 Office 转 PDF 清理、图片/PDF 框选修复。区域修复不能还原被覆盖的正文；PDF 区域修复会生成页图 PDF。新入口不代表新增万能无损移除算法。

帧重叠使用 Compose 的 [GraphicsLayer 记录和位图捕获](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)；周期更新使用已有 WorkManager，按 [唯一周期任务更新](https://developer.android.com/develop/background-work/background-tasks/persistent/how-to/update-work) 管理配置变更。相机路由不抓取 SurfaceView 静帧，直接保留实页轻位移，避免复制相机实例。系统可能按电量/网络状况推迟每日检查，不承诺精确 24 小时触发。

自动更新只查询配置的仓库并下载适配当前身份/架构的新版本；不会自动上传原始文档，不静默安装。默认关闭自动更新，启用通知在 Android 13+ 请求系统权限；拒绝通知仍可在更新页查看状态和下载结果。

本批阅读了本地已有 `libenhance4draft` / `libmagicenhancer` 的反编译入口和辅助处理线索；这些是伪代码及不完整的调用语义，不是已验证的完整原源码。保留现有私有模型，新增支撑/去噪实现为原创 Kotlin/OpenCV；DocRes 权重、来源和许可不变，没有加入新的私有模型或宣称重新训练。

重置只作用于参数。文档、历史、系统授权、应用锁、凭据及已保存档案不作为普通参数自动清除。界面中的传输/备份/导入等操作也不当作配置恢复执行。

## 实图与验证

本批使用同一机主原图 P3、参考截图 P1 和上一审核包结果进行对照；图像与参考保留在仓库外。没有声称已达到参考 App 或所有照片的统一质量；密集反页笔画仍可能被前景模型误判，淡铅笔与孤立数学符号需继续核验。

最终实际指标、定向检查结果与 APK 大小见随包审核资料。只针对本批入口、分组重置、自动更新调度、过渡和实图处理验证，不重复运行历史全套。

### 同几何对照与限制

本轮未修改几何网格，故额外使用同一个基线配准矩阵比较滤镜，避免清理结果改变 SIFT 特征后配准漂移。分析宽度 900px，沿用原参考空白定义：暗痕占比 0.08337% → 0.07913%（约减少 5.1%）；平均残墨 0.11991 → 0.11465；严格二值墨迹 IoU 0.37118 → 0.37498。该改善较小，不能称已消除透印。

原有“每图独立配准”也完整保留：暗痕占比反而从 0.08337% 到 0.10654%，IoU 从 0.37118 到 0.34395。清理引起特征点变化，重新估计的配准也不同；不选择性丢弃这些回退结果。对同几何滤镜对照优先看固定配准，仍需多张人工标记图验证文字保留。不能把上一轮约 42% 的改善重复计为本轮收益。

资料包含参考/上一审核/本批对照和实际 PDF；没有把模拟器缓存命中约 10 秒当成首次推理速度，首轮离线 AI 仍可能明显较慢。

### 定向验证结果

5 个相关设备场景已分别通过：工作台/扫描编辑器去水印及当前草稿 PDF 带入；扫描单项与分组重置且导出参数保留；自动更新网络约束变更和取消；新页面立即挂载/过渡及项目主页顺序；实际原图处理与 PDF 输出。入口测试的两次补跑修正了测试对合并语义和多窗口截图的选择方式，未将测试定位问题作为产品算法问题。

完整 Debug 与设备测试包已编译。没有重跑历史 OCR/Office/水印后端全套；自动更新这里只验证调度与关闭，真实服务器新版本下载/安装仍需在有适配新 Release 时验收。ARM64 审核包另核验包名、2.0.0/20003、证书、ABI、ZIP/ELF 16KiB、现有模型哈希及来源清单。

交付前截图检查发现长快捷标题使同排按钮高度不同，已统一四格高度并采用简短快捷名称；工作台分类网格仍沿用现有适配逻辑。
