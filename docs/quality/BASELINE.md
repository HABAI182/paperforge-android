# Baseline before quality changes

Baseline production source: `4d56d556aab3241c96f1584b869e947b1f330bb9` (v0.2.0). Frozen copies under androidTest/quality allow the same engine to run again after refactoring. Capture date 2026-10-23 (Asia/Shanghai). No phone or closed-source competitor run was available.

## Fixed corpus

82 **synthetic** cases generated by `scripts/bench/generate_fixtures.py`, seed 20261023: 64 multi-scene paper cases, 8 no-document negatives, 8 mixed OCR/orientation cases, the retained v0.2.0 regression photo (also synthetic), and one 12 MP resolution case. Manifest with exact SHA-256 and human-authored OCR strings: fixture-manifest.json. These are not real phone photos. Private owner photos remain ignored in bench-private/.

Variants 0–3 are development examples; variants 4–7 are held out for aggregate validation. No new algorithm has run when this baseline is recorded. Physical camera, wood/white-desk photographs, paper curvature, battery/thermal and 50 MP hardware performance are [device pending].

## Repeat

Use Python 3.12 and scripts/bench/requirements.txt. Run `scripts/bench/benchmark.ps1 -Python <venv-python> -Adb <adb> -Mode baseline`. Android 15 scoped storage rejected shell-owned external files; the debug harness instead copies explicitly selected fixtures via /data/local/tmp into the app's private benchmark directory using run-as. No app storage/network permission is added.
