# PaperForge 1.0.1

本版聚焦阅读界面、功能分区、主题和更新反馈。完整功能APK版本码10004，沿用原应用ID及所有者证书；保留历史tag和Release。扫描、OCR、Office及格式转换算法未在本版重写。

## 已完成

- 阅读页保留四个主要底栏动作，视图有明确文字入口。全屏、左右翻页、连续滚动、页面适配、纸张颜色分区；目录、书签、朗读、翻译等进入阅读工具。
- 统一卡片用于工作台、格式族、PDF用途分类、设置和阅读视图。子分类返回父级，文档布局入口直接显示，PaperForge主标题加大。
- 默认常用工具四项。升级时仅补全空列表；已有自定义列表保留，之后可主动清空。
- 检查更新后显示结果，下载/安装是后续显式操作。对最新版本、发现新版、服务失败和无适配架构分别处理。
- 共享主题模块提供六种外观、八种主题色，跟随系统实时响应明暗。背景、卡片和联网页面使用同一配色；专属主题与壁纸动态色的关系在设置中明确显示。

## 本轮验证

针对新导航、默认常用工具、视图、全屏、卡片返回、主题和更新反馈执行集中检查。一个本地HTTP协议设备测试覆盖最新/新版/服务不可用/架构不适配，不重复运行未改动的原生转换与扫描算法套件。

截图与逐项结果见[v101-ui](../acceptance/next/v101-ui/)。正式安装包的源提交、签名、ABI、字节数、SHA256与16KiB对齐以发布附件清单为准。

## 原有范围

原计划的92 done / 6 partial以及国际化、ViewModel拆分、DataStore迁移等工程状态沿用[1.0.0记录](V1.0.0-STATUS.md)，本版不将它们改写为全部完工。实体手机实拍、完整TalkBack、折叠屏与长任务性能仍按对应证据判断。

源码和下载公开后不需要GitHub令牌；所有者签名私钥与访问凭据不进入仓库。组件/模型来源和许可继续单独列出，项目公开不更改其原有声明。
