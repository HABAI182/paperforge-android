# 0.4.0 扫描、文档多选与自定义

本轮基线 v0.3.0 / ef521998438a8a335187615978b2e7bee62d36e3。针对用户明确反馈的取景/自动拍摄和自动裁边问题修改，而非重做已通过的OCR开发集。

## 相机链路

- 预览、分析和拍照绑定同一个CameraX UseCaseGroup/ViewPort。分析遵循ImageProxy.cropRect和旋转，显示轮廓通过1.4.2的ImageProxyTransformFactory/CoordinateTransform映射到PreviewView，移除按宽高比猜位置的实现。
- 发现界面尺寸改变会反复解绑/重绑相机，可能中断拍照。绑定改为每次进入相机建立一次，提示和缩略图底栏固定尺寸；实际模拟器快门→保存→编辑流程通过。
- 使用新鲜的原始检测四角作为照片提示，默认沿用取景纸框并在原照片上精修，不把显示平滑的四角直接写入照片。无有效提示时用照片检测；该行为可关闭。
- 自动拍摄默认稳定等待600ms、最短间隔1500ms、最小纸张面积8%，均可调。模糊/亮度门控改为可选；手动快门独立可用。同位置换页使用纸面8×8签名，连续两帧内容变化可解除重复锁；均匀曝光变化不作为换页。

## 直接复用的实现

直接适配MakeACopy固定提交01bebd394b9dd6f3a692f28aea7c0638085eb4da的DocQuadLetterbox、DocQuadScore、DocQuadPostprocessor，保留版权和Apache2完整文本/NOTICE。去掉Lombok和原app runner重载，包名改为PaperForge。未修改的DocQuadNet-256 ORT模型13,404,960bytes随包，256方形黑色letterbox、RGB float01 NCHW、四角热图+mask、二次峰值精修；CPU2线程的ONNX Runtime Android1.24.1。运行时无需下载。

默认混合模式先比较AI和传统边缘；一致时保留传统高分辨率精修，AI低分/失败回退传统；高把握的分歧可选择语义候选。用户可选传统边缘。模型缓存是应用内的可再生文件，不修改文档原图。模型NOTICE中的数据来源限制保留，不声称训练数据已独立审计。

固定82张合成开发集，65正例平均IoU **0.99709**，平均角点误差 **0.07930%**，失败 **0/65**，无纸误报 **0/8**，与v0.3相同。混合检测p50/p95 **170.76/217.33ms**（旧147/191ms），多了模型成本；11例AI与传统一致，0例语义替换。该集合只证明未退步，不能证明AI准确率超过传统算法。原始逐图记录见v040/，没有重复运行100页压力或完整9页OCR。

另从上游固定提交读取一张已有手机照片，保留文件哈希和近似手工四角标注，不提交照片本身。得到IoU0.99775、平均角点误差0.09089%，AI和边缘一致。只有一张探索样本，训练重合未知，不能作为独立真实照片准确率。它也不等同于本轮连接手机拍摄。

## 多选与配置

最近文档、文档库、回收站均可通过“多选”或长按进入；显示勾选数、全选/取消全选；批量收藏、分类、分享PDF ZIP、合并已有PDF、回收/恢复和一次确认直接删除。改变搜索或筛选会退出选择，避免隐藏项目被误操作；批量分类空字段保留原值。最近列表按修改时间排序，不被收藏优先顺序干扰。

首页齿轮集中提供扫描引擎、拍摄模式/等待/间隔/面积、质量门控、纸框、默认滤镜和增强、OCR语言、文字层、纸张/DPI/画质、主题/颜色/字体、紧凑列表/最近数量以及快捷入口显隐排序。设置即时持久化，可导出/导入JSON。文档及安全锁不在设置JSON中。自定义DPI在排队导出时固定，源像素与内存预算仍限制实际清晰度。

## 验证边界

最终安装包额外手动核对：导出包含默认值的27项设置，经系统文件选择器导入成功；多选1页扫描和3页原生PDF生成ZIP，两个PDF均可提取文字。三种架构包的641个非原生/非签名公共文件一致，签名、权限和16KB对齐记录随验收目录保存。

15项JVM、3项多选/设置/真实CameraX模拟器UI、4项模型/既有OCR-PDF-历史回归通过；Lint0 errors/38 warnings。模型在无GMS/飞行模式运行。早期失败与修复记录见acceptance/v040/summary.json。新增外观/多选/预览截图来自模拟器，所有扫描材料为生成材料或上游公开样例。

ARM64手机的实际相机FOV、AF时序、低光/反光、同位置翻页、电量温升仍需实机验收；尚无与CamScanner同手机同照片的比较。原图/历史/Room6/备份/离线约束保留。不能把新模型或反编译观察直接当作成熟竞品同等质量的证明。
