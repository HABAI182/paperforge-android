## 用户实测反馈（1.2.0 测试包，待修）

1. **滤镜回归（最高优先级，已有 agent 在跑）**
   - 调节强度面板遮住整个文档，无法边调边看 → 改为不遮挡并实时刷新
   - 练习册提亮过头、字发白
   - 清晰文字阴影过强
   - 柔和黑白白纸出现黑色噪点
   - 主观不如 1.1.0（用 `git show v1.1.0:...EnhancePipeline.kt` 只读对照）
2. **分享处理**：只能转发微信，没有“保存到本地 PDF”；转发后返回扫描全能王又回到 PaperForge，要清后台才行（返回链路问题）
3. **票据入口找不到**：需要在文档卡、编辑器更多、首页工具三处可达；无 OCR 时能一步识别
4. **文件夹没实际作用**：不能新建/重命名/移动；默认页是“最近”，第一屏看不到文件夹入口
5. **动效缺失**：界面切换没有过渡，要 iOS/ColorOS 那种丝滑感（Compose 动画/共享元素，尊重减少动效设置）
6. **裁切/畸变**：拍摄裁切仍不准，希望接近系统“超级文档”效果
   - 事实：vivo/小米/OPPO/三星的“超级文档/扫描模式”都是厂商私有，**Android 没有公开 Intent/API** 可调用；只能自研，或走厂商 SDK 合作
   - 逆向 CamScanner 的内容只能当行为参考，不能复制代码/模型（用户要求复制，已明确拒绝原因）
