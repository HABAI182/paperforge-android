# 手机特殊格式转换

转换中心可搜索格式名称；可固定常用入口，也可在批量转换中选择“特殊文档 / 漫画”。原件与结果关联到持久任务，关闭界面后继续处理，结果可回到原件 / 实际结果对照。

| 输入 | 手机引擎 | 当前结果与范围 |
| --- | --- | --- |
| XPS / OXPS | 格式引擎 · MuPDF 1.28.5 | 固定页尺寸、页序、文字、图像与基础矢量转 PDF；可输出 PNG 页包 |
| SVG | 格式引擎 · MuPDF | 按该引擎可绘制的 SVG 内容转 PDF / PNG；不运行脚本，不保证全部 SVG / CSS / 滤镜效果 |
| CBZ | 格式引擎 · MuPDF | 按引擎识别的漫画页序转换图像，不识别成文字 |
| FB2 | 格式引擎 · MuPDF | 中文正文与图像重排；A4 / A5、10 / 12 / 16 / 20 pt 可选 |
| EML | 格式引擎 · Apache Mime4j 0.8.15 / MuPDF | 解码 MIME 与字符集、邮件头、HTML / 纯文字和 CID 内嵌图片；附件名称列在正文，原始附件留在 EML 原件 |
| PDF 容器 CAJ / KDH | 格式引擎 · 容器适配 / MuPDF | PDF 改名的 CAJ、经典 PDF 对象容器、KDH 内含 PDF；补建缺失页树后核对声明页数。HN / C8 / TEB 图像型 CAJ 尚不支持，会明确提示 |
| LaTeX .tex / 项目 ZIP | 格式引擎 · 正文适配 / JLaTeXMath / MuPDF | UTF-8 常用正文、标题、列表、基础表格、脚注、图片、分数 / 根式 / 积分 / 矩阵等数学。ZIP 使用 main.tex，或单一主 TeX 文件；支持项目内 input / include |
| DXF | 手机 Office 引擎 · LibreOffice Draw | 二维图纸线条、图形与文字转 PDF，也可使用 Office 图片页包。缺失图纸范围时在工作副本中补齐文字边界，避免上游自动范围裁掉文字 |

LaTeX 为明确的常用结构排版，**不是完整 TeX 编译器**；不运行宏包、TikZ、BibTeX 或外部命令。未支持命令 / 环境及坏公式保留原文并列入报告。公式以 300 DPI 图像嵌入，可选择同时附公式原文。显式分页使用内部 EPUB 章节，避免 HTML 引擎忽略分页。

DXF 不等于 DWG / DGN 支持；三维实体、外部参照、专有对象与缺失 CAD 字体仍受手机 Draw 引擎限制。已有显式模型范围按原件保留；缺失范围的文字包络为保守估计，可能增加留白。

## 输出与恢复

固定版式保持原纸张；FB2、EML 与 TeX 使用所选纸张和字号。DPI 用于页面图像和预览，原生 PDF 中可映射的文字与基础矢量保持对象形式。对可处理的嵌入字体执行子集化，并将生成的 Unicode 映射统一成规范 UTF-16BE bfchar，避免手机解析器跨字节区间漏字。部分 CFF 中文字体仍保留较大数据，不能保证所有小文档都得到小体积；实际大小写入报告。

逐页 PNG / 元数据与最终原生 PDF 存在独立格式引擎缓存；主应用持久保存页面包、来源哈希、版本化输出和报告。切换 PDF / PNG 输出复用已有页面包；旧结果不覆盖，文件名沿用用户名称。任务、原件、结果与对照通过现有资源备份规则恢复。

转换是新副本；源包签名、证书、链接 / 交互和目录未迁移或验证。报告保留可用文字坐标、页面几何、公式原文、附件名称和转换提示；图片包只引用实际包含的资源。

## 引擎来源

手机格式引擎独立签名安装，主包保持无网络权限。MuPDF 的官方 AAR 固定 1.28.5，限定 64 位 ABI；原生库 16 KiB 对齐由交付脚本核对。开源许可和来源固定记录随格式 APK 打包，详见 `format-engine/src/main/assets/native/`。DXF 使用现有可选 Office APK，无需电脑。

验收与边界见 `docs/acceptance/next/special-formats-summary.json`；模拟器与独立文件复读仅证明所列样例，不代表全部真实文件兼容性。
