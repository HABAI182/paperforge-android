# 纸匠 PaperForge 0.6.1 · 扫描完成后看得清

扫描后编辑器改为大画布，可左右翻页、双击/双指放大、拖动检查和全屏。文档名点按修改，增强和缩略图按需展开，重拍/旋转/删除/撤销均保留。

回收站固定在顶栏，支持多选恢复和直接删除。首页搜索置顶、真实文档封面、扫描悬浮按钮；统一字阶、圆角和表面层次，增加系统动态配色与纯黑主题。

去阴影不再把彩色内容转成灰度；新增清晰滤镜和同裁边原图对照。编辑页“更多”可导出本页诊断包，含原图、增强结果、坐标与处理耗时，留在手机本地。

普通手机安装 `PaperForge-0.6.1-arm64-debug.apk` 覆盖旧版。通用包供 ARM64/x86_64 使用。Office 引擎继续沿用本仓库 0.6.0 的手机引擎，无需重新安装。

本版完成 5 个聚焦 Android 检查，编辑器另补实际图像与诊断包检查；16 个单元检查通过，lint 无错误。交互环境为 API35 x86_64 模拟器，尚无实体 ARM64 手机或竞品同图质量结论。

计划并未全部完成：98 项中 12 完成、19 部分完成、67 待做。详细边界见源码 `docs/quality/SCAN-EXPERIENCE-0.6.1.md`。源码与本 Release 均保持私有，旧 tag/附件保留。
