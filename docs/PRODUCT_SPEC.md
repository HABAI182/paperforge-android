# 产品范围与验收

需求来源：用户提供的 `android_pdf_scanner_codex_prompt (1).md`。2026-10-23 用户补充：直接开工，可自行补全，产品完全不商用或营利。该补充覆盖原文的未来闭源商业化假设。不开账户、付费、服务器或云同步。

当前 0.2.0 的补齐与扫描/OCR 修复见 [版本记录](CHANGELOG-0.2.0.md)。以下表格和后续计划保留为 0.1.0 的范围基线。

## 0.1.0 实现的纵向切片

| 功能 | 实现形式 | 验收类型 |
|---|---|---|
| 首页与本地库 | Compose Material 3、名称搜索、重命名、删除 | UI + 实际启动 |
| 相机 | CameraX 预览、闪光灯、手拍/连续、稳定自动拍摄、防重复 | 模拟器 + 待真机 |
| 检测与裁切 | OpenCV Canny/轮廓、多边形、归一化四角、拖动放大镜、透视变换 | 合成图像 + 交互 |
| 增强 | 原图、CLAHE 灰度自动增强、灰度、自适应黑白、彩色增强、参数 | 图像管线 |
| 草稿 | Room 文档/页面、私有原图、修订号、即时参数保存、编辑撤销重做 | 数据回读 |
| 页序 | 缩略条选择、前移/后移、删除、旋转、增页 | 数据 + 交互 |
| PDF 导出 | 逐页处理、A4/A5/Letter/原比例、质量、WorkManager 进度/取消、另存分享 | 文件结构 + UI |
| PDF 阅读 | 连续懒加载、有限缓存、缩放、页码跳转 | 模拟器 |
| PDF 工具 | 合并、顺序抽页/拆分、旋转、文本提取、有损图像压缩 | 原生文本保留测试 |
| OCR | 内置中文/Latin 模型、校正/复制/TXT | 首次离线、无 GMS |

## 0.1.0 时记录的后续项

- M1 体验补齐：拖拽排序、滤镜实时小样、批量套用、重拍替换、相机缩放/曝光控件、原图长按对比、纸张比例辅助裁边。
- M2：PDF 页缩略图导航、PDF 转图片、裁切/插入/水印、更多压缩策略、100 页压测、取消长任务覆盖。
- M3：OCR 坐标/语言/阅读顺序结构化存储、嵌入中文字体与文字层、旋转透视回归、CER/WER 样本集。
- M4：批注/手写签名/表单、文件夹/标签/回收站、离线备份恢复、持久撤销记录。
- M5：书页展平、手指/手写去除、表格结构与 Office 转换。每项单独比较样本与设备成本。

## 第一轮实机验收

首次安装后开启飞行模式，用真实 A4 拍十页，其中包含倾斜、阴影、浅色铅笔和中文；调角/排序后导出。外部阅读器核对页数、比例与清晰度；识别中文并导出 TXT；强制停止再启动能找回原稿和参数。具体状态不得用合成样本结果替代。
