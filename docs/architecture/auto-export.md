# 条件自动导出

规则默认关闭。文件夹条件匹配自身及子文件夹，标签条件按空格或逗号分隔并要求全部满足；两个条件同时填写时同时匹配。留空表示该条件不限。启用会处理当前匹配文档和后续变化，用户也可以仅手动运行一次。

每个规则保留一个 PDF 输入配方的副本、逻辑目录和扫描导出参数。扫描文档先按冻结的页面状态生成 PDF；已有 PDF 直接保留原页。配方负责后续 OCR、压缩、格式转换、命名和保存。规则中可以只保留本地成品，也可以包含一个或多个保存步骤。

应用只在存在启用规则时观察文档、页面及处理队列。页 ID/顺序/修订、OCR 记录及文字摘要与文档名称/分类构成源指纹；OCR 完成或校正可以触发更新。捕获任务尚未完成时等待，稳定延迟内发生新变化时旧任务会跳过，由新指纹任务接续。规则启用周期是显式批次，重新启用可以再次处理已有匹配文档。

Room 保存 `AUTO_EXPORT` 意图、来源快照和资源引用，WorkManager 执行。扫描快照包含页面设置、已有校正信息及依赖资源；后台槽位与其他重流水线共用。扫描基础 PDF 和配方各阶段完成后可复用；修改规则或源内容产生新任务，调整某个失败任务则可以沿用该任务的冻结输入与已完成阶段。

同一启用周期、源状态与处理参数只自动提交一次，失败和取消记录也参与去重。工作返回失败后不自动 `retry`；目录或提供程序不可用时保留原件、已生成的 PDF 和阶段结果。界面提供保留当前配置的继续重试，以及调整配方/保存目录后继续；任务中心另有按当前 OCR 设置重试的入口。

自动成品进入导出记录，不自动注册成新的文档库输入，避免输出再次匹配自身。关闭或删除规则取消其活动任务；已经生成的结果和原件保留。备份会映射扫描快照内的页/文档/资源，移除设备目标 URI 和保存阶段完成标记；当前设备需重新授权目录。

文档持续新增页面或稍后编辑时，可以生成下一份稳定版本；等待时间由用户配置。云盘离线时的阻塞时长由 Android 提供程序决定，失败记录允许用户自行恢复；没有隐藏的周期网络重试。

实际条件触发、排除、失败去重、保留阶段、界面创建启用/关闭和目录成品哈希见 [验收记录](../acceptance/next/auto-export-summary.json)。没有把真实云盘断网、系统强杀或各 OEM 后台策略视为已经验证。
