# 手机阅读重排

普通阅读器的“重排”打开独立全屏阅读面板，按需处理当前物理页。原生文字优先，无可用文字时使用当前离线 OCR。相邻且字号/缩进/行距相近的行合并成段落，再由 Compose 按阅读字号和行距换行。左右栏顺序可自选，复杂文章顺序不冒充自动语义理解。

PDF 中实际放置的图片保留其显示页区域，从原生渲染像素生成阅读图片；图片占据可用阅读宽度。实际检测到的表格线使用现有表格引擎保留单元格及合并关系。单元格按当前字号测量高度，横向滚动保留宽表，并可切回原样图片。自由表格、公式和扫描插图不能稳定识别时仍有完整原页对照。

每个段落、图片、表格和原页对照都保留归一化区域。点击“原页位置”使用 `FitR` 回到对应源区域，并加入原阅读锚点历史；“返回阅读处”恢复进入前的缩放/平移。单纯退出重排会同步当前物理页，随后再次打开可继续阅读。

页码、段落位置、偏移、字号、行距和栏顺序按文档保存，`ReaderPreferences` 导出和恢复时一同映射文档 ID。阅读缓存用源 PDF SHA、页号、引擎/识别参数、栏顺序及实现版本区分，保存在可重建缓存目录；原 PDF 不被替换。补识别只针对明确请求的页，翻回该页不会隐式再次识别。

实际界面、原图颜色、合并格编号、回跳返回及配置恢复见 [验收记录](../acceptance/next/reader-reflow-summary.json)。
