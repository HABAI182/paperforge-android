# 原页文字选择

原生文字保留 PDFBox 实际返回的 `TextPosition` Unicode 簇、行内偏移和显示页坐标。字形连字不会人为分割。OCR 使用真实词框；词框覆盖不完整、校正后缺失或引擎仅返回行框时，回退为整行，界面明确说明。

长按使用词边界初始化选区，两端手柄随后按实际单位调整。选择使用阅读器同一套显示裁边、适宽/适页、缩放和平移变换；手柄保持屏幕触摸尺寸。手柄从按下后直接跟踪位移，不丢弃普通滑动手势的初始触摸距离。

复制按选择的行顺序或左右栏顺序拼接，保留行内原始空格和编号。选择跨行时，每行分别加入标准高亮/下划线/删除线批注草稿，统一原子写入，不用一个大矩形跨越栏间。原件不修改；批注页继续负责可编辑或固定导出。

阅读设置、空白处长按后的文字面板、选择栏“更多”均有区域识字入口。圈选在源页坐标内生成区域，渲染后按实际像素裁切，离线 OCR 的词/行框逆映射回显示页。区域结果只供当前阅读选择和朗读/摘录使用，不冒充原 PDF 文字层，也不覆盖原件或全页识别缓存。

选区限定当前物理页，完成选择后继续翻页。多栏顺序可自选并纳入外观配置档案。实际手势、复制、圈选和独立渲染的记录见 [验收证据](../acceptance/next/reader-selection-summary.json)。
