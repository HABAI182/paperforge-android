# 0.5.0

- 有纸框时不每帧运行两套检测器。显示框短时丢失保留至260ms，大幅跳动需连续候选确认；拍摄仍使用新鲜原始四角。
- 对焦点直接使用原始检测中心映射，不受显示纸框延迟影响。

- 0%校正直接复制像素，避免重采样。
- 官方MNN3.6.1静态链接、CPU双线程，支持ARM64/x86_64及16KB结构对齐，固定源与模型来源随包记录。
