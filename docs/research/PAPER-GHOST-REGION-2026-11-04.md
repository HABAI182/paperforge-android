# 区域先验的透字抑制：位置信息能不能换回幅度做不到的门槛（第七步）

2026-11-04。承接 `PAPER-SCORE-2026-11-04.md`（换平面 + 每页分位把 AUC 做到 0.820，但 99.99% 门槛仍过不了）、
`PAPER-PAIRED-2026-11-04.md`（没有真实正/反配对；完美双面减法上限 0.9953/0.7868）、
`PAPER-MULTIFRAME-2026-11-04.md`（单帧合成 0.4979@99.99；多帧最好 0.5614）与
`PAPER-FLATFIELD-2026-11-04.md`（残差地板高于真值门限）。

机主假设：透字应该结合“它应该出现的区域特征”——空白区、两条横线之间的空隙带。本轮把它做成
**区域感知的透字分类/抑制候选**，只做离线实验；权重、缓存与训练数据全部在仓库外
`work/model-lab-20261103/ghost-region/`，`app/`、模型资产、`scan_params.json`、版本号未改，
没有任何 git 写操作，没有 Android 构建。

## 结论先行

1. **真实页目标没有达到，而且差得很远。** 99.9% 淡字保留（archived 掩膜）下，
   context-v2 透字排除 **0.0005**，区域模型 **0.0018**；目标是 **0.85**。
   可见淡字（photo ink ≥0.03）口径下区域模型 **0.0243**（context 0.0016），仍差 35 倍。
2. **本轮最大的数字纠正：简报里的 0.5 / 0.85 不是真实页数字。** 20 页缓存上真实页
   context-v2 在 99.99/99.9/99/95% 淡字保留处分别是 **0.0000 / 0.0005 / 0.0097 / 0.0532**。
   0.4979@99.99 与 0.7622@95 量级来自合成夹具（`PAPER-MULTIFRAME` / `PAPER-SCORE`）。
3. **99.9% 门槛在真实页上首先是一个度量问题。** archived faint = truth & photo ink<0.06，
   其中 **31% 像素 ink<0.005、46%<0.01**（基本不可见或配准残差）。按 99.9% 保留取阈值，
   阈值落在 1e-10–1e-3，绝大多数灰痕分数都在阈值之上；任何非负分数都很难在这个门里排除灰痕。
4. **区域先验在“普通页”上确实有效，但被 page 24 一个人口页拖垮。** 逐页 AUC
   （faint vs ghost31）：区域模型 **0.801**、context-v2 **0.534**；逐页 99.9% 门槛的
   灰痕排除均值 **0.210 vs 0.008**。但 page 24 占全部 faint 的 **46%**，其自身 AUC
   **0.238**（模型把“整页淡字”当成灰痕），pooled AUC 被压到 **0.507**。
   去掉 page 24 后 pooled 99.9% 也只有 **0.029**，仍远低于 0.85。
5. **空隙带先验在真实代理掩膜上几乎不分离。** faint 落在行空隙带的比例 **0.734**，
   ghost31 是 **0.777**、ghost4 是 **0.769**；gap 单特征 faint-vs-ghost AUC **0.541**。
   区域先验把门内灰痕压得比门外多（99% 门槛：带内 0.0107 / 带外 0.0007），但同时把带内
   faint 也压掉（95% 门槛 faint 带内 0.9408 / 带外 0.9939）——这就是这个假设的固有取舍。
6. **合成 side 证明机制成立，但不外推。** 90 个留出夹具上区域模型 AUC **0.9926**，
   99.9% 门槛 0.572（context 0.092）；其中“透字只在空隙带”（mode 1）**0.656**，
   “透字全页均匀”（mode 0）**0.473**。区域先验只在 mode 1 的假设下多买到约 18 pp，
   而且这仍然不是 0.85。
7. **“反页透字先验”救不了。** 用平板扫描差 `blur(max(ink−inkScan,0))` 作为 oracle
   输入，模型 99.9% 门槛只从 0.0018 提到 **0.013**、AUC 0.507→0.545；
   该先验单独作为分数 AUC 只有 0.314（取反 0.686）。它不是一个干净的双面证据。
8. **幅度消融：大部分增益不是区域平面买的。** 同折同步数、只保留 4 个幅度平面，
   页均 AUC 从 context-v2 的 0.534 到幅度-only **0.777**，再加油区域平面到 **0.801**
   （faint_vis 0.800→0.837）。也就是说，混合合成训练 + 淡字重权 + 两尺度上下文是主因，
   区域先验只加 **+0.024 / +0.037 AUC**；逐页 99.9% 门槛 0.133→0.210。
   本轮不把主要增益归因给“空隙带”本身。

## 数据、真值与口径

### 真实页（公开、仓库内 `bench-private/docunet`）

20 组可配准页：同一页的相机照片 + 平板扫描（SIFT 单应，内点 60–619）。
沿用 `score-mapping` 的 float32 缓存与掩膜定义：

- `truth` = 平板 ink >0.15（映射进照片帧，valid 内）；
- `faint` = truth & photo ink <0.06；
- `ghost31` = 归档代理：离 truth ≥31 px 的扫描空白、photo ink 0.012–0.30；
- `ghost4` / `ghost6` = 紧掩膜（≥4 px / ≥6 px）；`ghost6` 用于训练监督，
  `ghost31` 用于和归档数字对齐，`ghost4` 用于减少“标签几何”捷径。
- 本轮另加 `faint_vis` = faint & photo ink ≥0.03，作为“看得见的淡字”口径。

规模：faint 504,644 px；ghost31 221,143 px；ghost4 767,485 px；ghost4/ghost31 = 3.47。
page 24 一页贡献 232,343 faint（46%）与 129,409 ghost4。

### 合成页（程序生成器）

`rg_core.synth_page` 生成 256×256 页：文本/表格/横线/公式块、逐块对比度
（log-uniform 0.035–0.85，至少一块 0.03–0.09 的淡字）、镜像背面层（σ 1.2–3.6，
增益 0.03–0.22）、shade、椒盐/Gaussian 噪声。背面层有三种放置：

| mode | 放置 | 用途 |
|---|---|---|
| 0 | 全页均匀 | 幅度上限对照 |
| 1 | 只落在前层行空隙带（0.15+0.85·gap） | 机主假设的理想情形 |
| 2 | 全页但空隙带加权（0.55+0.45·gap） | 中间情形 |

监督：front truth=1（权重 10，faint 14），未遮挡 ghost=0（权重 7），空白 0.15。
合成训练种子 20261105；评估种子 900000+，不重叠。

### 无泄漏协议

- **5 折按页留出**：每折 4 页（`[1,2,3,4] [5,7,8,9] [12,13,14,16] [17,18,19,20] [22,23,24,25]`），
  其余 16 页 + 合成块训练；所有真实页数字来自没见过该页的模型（OOF）。
- 合成训练/评估种子分开；超参数先验固定（1800 步、batch 16、lr 3e-4），不做逐折调参。
- 门槛只在留出页 faint 上钉死，不用真值拟合任何权重；oracle 先验单独标注。
- 31 px 掩膜与距离/空白先验部分同构，因此同时报 ghost4 与“去 page 24”敏感性。

## 特征集（10 个平面，9 个可部署）

| # | 平面 | 计算 | 部署 |
|---|---|---|---|
| 0 | ink | `1 − gray / medianBlur(dilate(gray), 3.5%·min)` | 是 |
| 1 | blur0.8 | Gaussian σ=0.8 | 是 |
| 2 | blur2 | Gaussian σ=2 | 是 |
| 3 | blur4 | Gaussian σ=4 | 是 |
| 4 | dist | 到 `ink>0.18` 强笔画的 L2 距离变换，/60 px clip | 是 |
| 5 | blank | `ink<0.02` 的 65×65 均值（局部空白度） | 是 |
| 6 | gap | 水平投影检测文本行；行间/页边 gap soft mask（0–1） | 是 |
| 7 | rowdist | 到最近行中心距离 /（1.15·半行距），0–1 | 是 |
| 8 | resid | `ink − blur65(ink)`，clip ±0.03 归一 | 是 |
| 9 | prior | `blur(max(ink−inkScan,0), σ=2)/0.10`，仅训练/ oracle | **否（推理置 0）** |

行结构只从 photo ink 计算（`ink>0.05` 水平投影，阈值 = lo+0.22(hi−lo)，闭运算去洞，
≥3 px 行才保留）；不碰扫描，所以推理合法。照片里有桌面/背景，这些先验会在整张照片上
计算，产品裁页后会更干净——这是本轮的一个域差，见限制。

### 训练前的单特征诊断（20 页 pooled）

| 信号 | truth vs ghost31 | faint vs ghost31 | faint vs ghost4 |
|---|---:|---:|---:|
| context-v2 | 0.639 | 0.457 | 0.562 |
| blur2 | 0.693 | 0.476 | 0.470 |
| dist（到强笔画） | 0.280 | 0.475 | 0.502 |
| blank | 0.433 | 0.551 | 0.582 |
| gap | 0.485 | 0.541 | 0.533 |
| rowdist | 0.489 | 0.564 | 0.557 |
| region4（dist+blank+gap+rowdist 均值） | 0.426 | 0.560 | 0.577 |
| ink | 0.557 | 0.191 | 0.195 |

读法：`dist` 的 truth-vs-ghost AUC 0.280 是“方向反了”（灰痕离墨远），取反是 0.720；
但 **faint-vs-ghost 只有 0.475–0.564**。也就是说“离墨远/空白”能把“正文 vs 灰痕”分开，
却几乎不能把“淡字 vs 灰痕”分开——而后者才是 99.9% 门槛要的东西。这也与
`PAPER-SCORE` 把密度/距离列为“掩膜几何捷径”的判断一致。

## 模型与训练

`RegionInk`：两尺度编码/解码 + 全分辨率跳接，输入 10 通道，width=16，
**54,097 参数**（context-v2 是 36,665）。BCEWithLogits，权重 front 10 / faint 14 /
ghost6 7 / 空白 0.15 / 近墨环 0.1。每步 batch 16 = 8 真实块 + 8 合成块（96×96），
随机水平翻转；合成块以 0.5 概率把 prior 通道置 0，真实块恒 0。
AdamW lr 3e-4、wd 1e-4，1800 步/折，5 折共 2,383 s（CPU，16 核里用 6 线程）。

幅度消融用同一代码、同一折、`--planes 0,1,2,3`（4 通道），1800 步。

## 结果 B：合成（机制验证，不可外推）

90 个留出夹具（30/mode），整体 AUC **0.9926**：

| 方法 / mode | 99.99% | 99.9% | 99% | 95% | 90% | 80% |
|---|---:|---:|---:|---:|---:|---:|
| 区域模型，全部 | 0.337 | 0.572 | 0.847 | 0.963 | 0.989 | 0.998 |
| mode 0 均匀 | 0.312 | 0.473 | 0.863 | 0.962 | 0.987 | 0.998 |
| **mode 1 只在空隙** | **0.539** | **0.656** | 0.891 | 0.988 | 0.997 | 0.999 |
| mode 2 混合 | 0.408 | 0.591 | 0.814 | 0.944 | 0.979 | 0.995 |
| context-v2（参照） | 0.023 | 0.092 | 0.353 | 0.764 | 0.918 | 0.981 |
| oracle prior 通道 | 0.187 | 0.633 | 0.958 | 0.997 | 0.999 | 1.000 |

- 区域模型比 context-v2 在合成上强一个量级，说明“blur/context + 区域平面”能学出
  “模糊低幅 = 灰痕、锐利淡笔画 = 前层”。
- **gap-only 比 uniform 只多约 18 pp（99.9%：0.656 vs 0.473）**；AUC 都在 0.99，
  因为合成 ghost 本身是模糊的，幅度/尺度已经能分开。区域先验的独立价值没有想象中大。
- oracle prior 通道在 99.9% 只到 0.633，说明“把真背面层当输入”也不是万能；
  99.99% 更低，因为分数尺度被重新校准。

## 结果 C：淡字可见度地板（为什么 99.9% 门槛不可用）

同一 archived faint 掩膜，抬高可见度地板后重算 99.9%（ghost31）：

| floor | 保留 faint 比例 | 模型阈 | 模型排除 | context 排除 | 模型 AUC |
|---|---:|---:|---:|---:|---:|
| 0 | 100% | 0.0008 | 0.0018 | 0.0005 | 0.507 |
| 0.01 | 53.5% | 0.0009 | 0.0030 | 0.0006 | 0.526 |
| 0.02 | 29.5% | 0.0028 | 0.0127 | 0.0006 | 0.678 |
| 0.03 | 17.4% | 0.0070 | 0.0243 | 0.0016 | 0.757 |
| 0.04 | 9.8% | 0.0164 | 0.0440 | 0.0029 | 0.790 |
| 0.05 | 4.2% | 0.0202 | 0.0496 | 0.0041 | 0.807 |

这条表是本轮最重要的“仪器修正”：**在不可见像素上做 99.9% 保留，等于把阈值钉在
地板；AUC 从 0.507 提到 0.807 的同时，门槛只从 0.0018 动到 0.0496。**
与其继续争 0.85，不如把产品目标改成“可见淡字 ≥99.9% + 灰痕可见度下降”，
并用可见度地板重定义 faint——这个决定需要机主拍板，本轮不替产品改口径。

## 结果 D：反页先验 oracle

平板差先验 `prior` 与模型喂 prior 通道（不可部署）：

| 信号 | AUC | 99.9% | 95% |
|---|---:|---:|---:|
| prior 单独 | 0.314 | 0.000 | 0.000 |
| 区域模型（可部署） | 0.507 | 0.0018 | 0.0158 |
| 区域模型 + prior 通道 | 0.545 | 0.013 | 0.098 |

结论：即使拿到平板差，99.9% 也只到 0.013。**缺的不是“反面证据”这一个通道，
而是这个证据在 99.9% 尾部也不够干净**（配准、纹理、阴影、扫描噪声都在里面）。

## 结果 E：幅度消融（同折、同步数，只把输入砍到 4 个幅度平面）

| 指标 | 区域模型（10ch） | 幅度-only（4ch） | context-v2 |
|---|---:|---:|---:|
| 参数量 | 54,097 | 53,233 | 36,665 |
| faint_all vs ghost31 页均 AUC | **0.801** | 0.777 | 0.534 |
| faint_vis vs ghost31 页均 AUC | **0.837** | 0.800 | 0.558 |
| front vs ghost31 页均 AUC | **0.869** | 0.843 | 0.708 |
| 逐页 99.9% 门槛均值 | **0.210** | 0.133 | 0.008 |
| 逐页 95% 门槛均值 | **0.414** | 0.370 | 0.123 |
| 99.9%（faint_all，pooled） | 0.0018 | 0.0014 | 0.0005 |
| 99.9%（faint_vis，pooled） | **0.0243** | 0.0067 | 0.0016 |
| 95%（faint_all，pooled） | 0.0158 | 0.0160 | 0.0532 |

读法（重要）：

- **大部分增益不是区域先验买的。** 从 context-v2（页均 0.534）到幅度-only（0.777）
  已经拿到 +0.243 AUC；区域平面再加 **+0.024**（faint_all）/ **+0.037**（faint_vis）。
  也就是说，混合合成训练 + 更重的淡字权重 + 两尺度上下文是主因，区域先验是小增量。
- 区域平面在 **visible faint 的 99.9%（0.0243 vs 0.0067）** 和 **80%（0.4715 vs 0.3573）**
  上有可见优势；但在 archived faint 的 95/90/80 反而略输幅度-only——因为区域平面
  把 page 24 型“整页淡字”压得更狠。
- 因此本轮**不能**把主要收益归因给“空隙带/空白区”假设；它只是在部分页/部分操作点
  上有小增量，且与“整页淡字”负迁移。

## 结果 F：ONNX 与耗时（桌面 CPU，不是手机）

`ghost-region.onnx`：10 通道、54,097 参数、225,938 bytes，SHA256
`37e458a9…fc946`；torch vs onnxruntime 最大绝对差 **1.8e-7**。

| 输入 | 模型中位 | 预处理（9 平面） | 合计 |
|---|---:|---:|---:|
| 1400×1050 | 253.7 ms | 75.5 ms | **329 ms** |
| 1000×700 | 119.5 ms | — | 119.5 ms + 预处理 |

预处理 = 3 次 Gaussian + 距离变换 + 65×65 盒滤波 + 行投影 + 残差（OpenCV 单线程）。
手机上要按 3–10× 估，且长边 1400 的平面内存约 60 MB；产品若用必须降分辨率或分块。
**本轮没有手机/Android 延迟数据。**

## 失败与限制

- **目标未达**：真实页 99.9% 0.0018（archived）/0.0243（visible），目标 0.85。
- **度量退化**：31% faint 像素 ink<0.005；99.9% 阈值在地板附近。任何在真实页报
  “99.9% + 高排除”的数字，先检查它的 faint 掩膜是否包含不可见像素。
- **page 24 人口页**：46% faint、模型 AUC 0.238；它一页决定 pooled 结论。
  本轮没有修好它（模型把整页淡字当灰痕）。报告同时给 page-mean 与去 24 数字。
- **掩膜是代理**：ghost31 由“离平板真值 ≥31 px”定义，距离/空白先验与它部分同构；
  ghost4 缓解但不能消除。真实透印/纹理/照明/配准误差混在一起。
- **区域先验弱**：gap 单特征 faint-vs-ghost AUC 0.541；faint 与 ghost 的空隙占用
  0.734 vs 0.777。机主假设在这份公开数据上不成立或至少不可测。
- **合成不可外推**：生成器是程序化的，不是纸/墨物理模型；gap-only 只证明“若透字
  只落在空隙带，区域先验能多买约 18 pp”，不证明真实纸页。
- **域差**：DocUNet 照片带桌面/背景，区域特征在整张照片上算；产品裁页后特征更干净，
  本轮没有裁页重测。
- **没有机主手机拍摄、没有真实双面配对、没有 Android/真机延迟**；ONNX 延迟只是
  Windows 桌面 CPU。
- **没有用机主私有页训练**（按简报跳过；如需用需先征得同意）。

## 是否值得接入

**本轮结论：不接入产品，至少不作为“透字抑制”上线。**

- 目标 0.85 未达；真实页 99.9% 只有 0.0018–0.0243。
- 若未来接入，建议只作为**可选分支**，条件是：
  1) 输入是裁好的页（不是带桌面的整张照片）；
  2) 口径改成 visible faint + 可见灰痕下降，而不是 99.9% archived faint；
  3) 在 page-24 型“整页淡字”上有独立门控（例如用每页淡字比例/对比度检测，禁用区域模型）。
- 与现有模型共存：`ghost-region.onnx` 是 10 通道、54k 参数（225,938 bytes）、输入长边 1400
  的独立候选；通道 9 必须置 0。桌面 CPU 上 1400×1050 模型 253.7 ms、预处理 75.5 ms，
  合计约 329 ms；手机没有测。它可以和 context-v2 并列打分，由域门控选择，不替换现有
  资产、不改 `scan_params.json`。
- 真正需要的是：**真实双面/机主手机页 + 可见度地板口径**，而不是继续在 20 页代理
  掩膜上加区域特征。
