# 分数映射与输入归一化：能不能把“同保护点的灰痕”换出来（第六步）

2026-11-04。承接 `PAPER-REAL-ATTRIBUTION-2026-11-04.md`（最便宜、收益最大的一步是分数映射 / 输入归一化）、
`PAPER-PAIRED-2026-11-04.md`（真实页 context-v2 71.48/52.45/40.41，537 探针 54.48/23.44/87.32）与
`PAPER-FLATFIELD-2026-11-04.md`（shade 是共模项，不改变门槛）。

本轮**只动后处理 / 特征层**：不改模型权重、不改 `app/`、不改 `scan_params.json`、不改版本号；没有 Android 构建；
没有任何 git 写操作。所有产物在 `work/model-lab-20261103/score-mapping/`，`docs/` 只新增本文件。

## 结论先行

1. **复现逐位一致。** 20 页 × 7 阈值 × 3 指标 × 2 模型 = **840 个数字，最大绝对差 0.0**；1px 容差另 840 个也 0.0。
   （中途用 float16 缓存试跑时差 3.1e-4，改为 float32 后归零——这类“看起来很小的差”足以移动阈边界，不值得省。）
2. **换掉第一个输入平面是这轮最大的单一杠杆。** 把 context-v2 的 plane0（锐利 ink）换成 σ=2 的平滑幅度，
   其余不动，真实页排序 AUC 从 **0.708 → 0.820**，淡笔画-对-灰痕 AUC 从 0.534 → 0.748。
   这直接印证归因文档的判断：可用的判别信息在平滑幅度里，锐利平面在真实照片上是噪声主导（页均淡笔画 SNR 中位约 0.22，13/20 页 |SNR|<0.5）。
3. **但只换平面不够，分数还要按页校準。** c 平面分数在“同保护点”下淡笔画只有 47.88%——不是排序差，是**跨页尺度不一致**：
   把分数做每页全 CDF 分位映射后，**同一个排序**在 pooled 阈值下变成 **57.53%**，灰痕从 65.83% → 68.03%。
   分位映射是严格单调的，**实测逐页 AUC 变化 0.0**（`recommended-check.json`），它买的是跨页阈值一致性，不是排序能力。
4. **推荐方案达标本轮目标，而且是零拟合参数。** `c 平面（blur2 打头）+ 每页全 CDF 分位`：
   **AUC 0.8202（>0.806）、淡笔画 57.53%（≥52%）、灰痕清理 68.03%（≥55%）**。
   逐页 18/20 淡笔画更好、17/20 灰痕更好、18/20 AUC 更高；剔除第 24 页后 57.4% / 79.6%。
5. **“免费项”单独就值 +3.0pp / +6.5pp。** 对现有 context-v2 分数只做每页分位映射（不动输入、不动模型）：
   AUC 0.7081（定义上不变），淡笔画 **52.45% → 55.40%**，灰痕 **40.40% → 46.93%**。这是本轮风险最低的改动。
6. **监督融合打不过手工融合。** 用 19 页真实标签做 LOO 的线性融合：AUC 0.809 但淡笔画只有 45.6%（不达标）；
   用程序夹具拟合权重搬到真实页：AUC 0.721、淡 52.7%、灰 48.0%（不达标）。**九个达标方案里没有一个来自监督拟合**，
   全部是“换平面 + 秩映射”的固定组合。
7. **这个修复是域特定的，不能全局替换。** 合成夹具上 context-v2 AUC 0.9777，c 平面只有 0.6974；
   夹具拟合的融合在合成上不掉（0.9745），搬到真实页就崩。⇒ **必须做域门控：只在低质 / 灰雾拍摄上启用**。
   现有的相关性证据：页级 AUC 增益与纸面 σ 的 Spearman 为 0.31–0.33（弱正相关，不足以下结论）。
8. **99.99% 门槛仍然过不了。** 真实页在正面保留 99.99% 时灰痕排除只有 0.00–0.02%（所有候选）；
   95% 保留时最好的候选 37.3%。合成侧 99.99% 淡墨保留处透印排除最好 0.407（context-v2），
   与 `PAPER-FLATFIELD` 的“门槛瓶颈是幅度重叠”一致——本轮没有改变它，也不假装改变。
9. **两个“捷径信号”被测量后排除。** 墨迹密度（61px 均值）AUC 0.725、到墨迹的距离 AUC 0.669——
   它们读的是灰痕掩膜“离真值 ≥31px”的定义，不是文档性质。任何用它们刷出来的 AUC 都是掩膜几何。

## 方法

### 掩膜（沿用，未改定义）

- 正面真值 = 扫描墨迹 >0.15（映射进照片帧）；
- 淡笔画 = 真值中照片墨迹 <0.06；
- 灰痕带 = 文档内空白（离真值 ≥31px）且照片墨迹 0.012–0.30；
- 逐页 20 组（弃用 6/10/11/15/21，内点 2–53）。

### 指标

- **排序 AUC**（阈值无关，页均）：真值 vs 灰痕带；另报淡笔画 vs 灰痕带、淡笔画 vs 纯纸。
- **同保护点**：把每个信号的 pooled 阈值调到与 context-v2 相同的**正面保留 71.48%**，再读淡笔画保留与灰痕清理
  （曲线在信号自身的分位网格上算，插值读点，避免固定 0.0005 网格的量化误差）。
- **保留门槛**：正面保留 95% 与 99.99% 处的灰痕排除率；合成侧另报“淡墨保留 99.99% / 95% 时透印排除率”。
- 逐页读数：每页在自己的 71.48% 正面保留处读淡 / 灰，用于 win/loss 计数。

### 两个仪器问题（本轮发现并修正）

1. **归档 AUC 只适用于 0..1 的信号。** `attribution_core.auc_binned` 用 `histogram(range=(0,1))`，
   z 分数 / 分位 / 秩信号的取值会整体落进端点 bin，AUC 被压到约 0.5。
   pilot 第一次就撞上了（`results/pilot.json` 里 `a_page_z` AUC 0.543，明显不可能——单调映射不可能改排序）。
   改为**精确秩 AUC**后，三个锚点与归档值差 ≤0.0011（binned vs exact：s0 0.7077/0.7081、537 0.8043/0.8032、
   blur2 0.8060/0.8060、blur4 0.8034/0.8034）。本报告所有 AUC 都是精确秩 AUC。
2. **合成侧归档数字是“跨夹具 pooling”，真实侧是“逐页平均”。** 两种口径混用会让“跨页尺度稳定”的信号占便宜。
   本轮合成侧一律**逐夹具平均**，另留 `s0PooledGate` 与归档口径衔接。

### 无泄漏协议

- **零参数方案**（分位映射、秩融合）：没有任何拟合量，只有设计选择。
- **秩融合权重**：19 页选、第 20 页用（LOO），准则 = “淡笔画下限 52% 下最大化灰痕清理”。
- **线性融合**：LOO 逻辑回归（特征 = 纸面 z 的 `[s0, blur0.8, blur2, blur4]`，L2=1e-2）。
- **夹具拟合**：两个从未用于任何 DocUNet 页的种子（拟合 20261106 / 90 个夹具，评估 20261105 / 60 个夹具），
  只用程序夹具拟合权重，再搬到 20 页。
- 全 20 页网格最优（oracle）只在正文里作为“选型乐观度”参照，**不作为结果**。

### 信号族

| 族 | 做法 |
|---|---|
| (a) 分数分位映射 | 每页纸面 z、每页纸面百分位、每页**全 CDF 秩**、滑窗局部标准化（65/129px） |
| (b) 分数×幅度融合 | 纸面 z 的 sum / max、秩融合（s0+blur4、c 平面+局部幅度、c 平面+blur2/blur4）、LOO 逻辑回归、夹具拟合逻辑回归 |
| (c) 输入归一化 | 大核背景（101px）重算 ink、滑窗对立化（31px 均值/标准差）、plane0 换成 blur2 / blur4 / max(ink,blur2) |
| (d) 多尺度门控 | blur4 分位硬门 + blur2、blur0.8/2/4 几何均值、三尺度取 min |
| 排除项 | 墨迹密度、到墨迹距离（掩膜几何捷径）；TPS 类局部重采样（上一轮已否决，本轮不用） |

## A. 分数分位映射（不改排序，改跨页阈值）

| 信号 | AUC | faint@71.48 | ghost@71.48 | ghost@95 | 说明 |
|---|---:|---:|---:|---:|---|
| context-v2 原始 | 0.7081 | 52.45% | 40.40% | 8.9% | 基线 |
| 每页纸面 z | 0.7081 | 53.66% | 37.91% | 12.4% | 用“空白像素中位 / p90”作尺度 |
| 每页纸面百分位 | 0.7080 | 53.43% | 40.11% | 6.4% | 用纸面经验 CDF 作映射 |
| **每页全 CDF 秩** | 0.7081 | **55.40%** | **46.93%** | 8.2% | 参照集 = 全页像素（仍无监督） |
| 滑窗局部 z（65px） | 0.6561 | 58.01% | 31.42% | 3.8% | 排序被打坏 |
| 滑窗局部 z（129px） | 0.7114 | 57.81% | 42.54% | 4.2% | 略优 AUC，灰痕仍差 |

三点读法：

- **单调映射不改变逐页 AUC**，这是定义，不是结论；实测 max \|ΔAUC\| = 0.0 只是校验。它改的是 pooled 阈值
  落在每一页的哪个位置。所以这一族**不能**用来追 AUC 目标，只能用来追“同保护点”的三个数。
- 参照集的选择很要紧：**全页 CDF** 比**纸面 CDF** 好得多（55.40/46.93 vs 53.43/40.11）。
  纸面 CDF 在“本来就没有纸”的页（第 24 页那种满页淡字）上会把所有像素推到高端，pooled 阈值反而失准。
- 局部标准化（滑窗）会把灰痕的局部起伏放大，灰痕清理从 40.4% 掉到 31–43%，**否决**：它把“区域偏置”当成信号。

## B. 分数×幅度融合

| 信号 | AUC | faint@71.48 | ghost@71.48 | ghost@95 | 备注 |
|---|---:|---:|---:|---:|---|
| 纸面 z：0.5·(s0+blur4) | 0.7977 | 45.96% | 63.61% | 31.4% | 线性相加 |
| 纸面 z：max(s0, blur4) | 0.7899 | 46.76% | 62.31% | 19.8% | 取大 |
| 秩融合 s0+blur4（LOO 权 0.3/0.7） | 0.7983 | 53.51% | 59.05% | 24.6% | LOO 选中权重稳定（15/20 折 0.3/0.7） |
| 秩融合 c 平面+局部幅度（LOO 0.3/0.7） | 0.8125 | 53.58% | 68.42% | 13.9% | LOO 17/20 折 0.3/0.7 |
| 秩融合 c 平面+blur2 50/50 | 0.8242 | 53.82% | 65.74% | 33.5% | 固定权重，无拟合 |
| 秩融合 c 平面+blur4 50/50 | **0.8246** | 55.34% | 65.45% | **37.3%** | 固定权重，无拟合 |
| 秩融合三路（c 0.4 / blur4 0.3 / 局部 0.3） | 0.8201 | 54.32% | 67.43% | 28.3% | |
| LOO 逻辑回归（19 页训练） | 0.8090 | 45.59% | 58.47% | 10.5% | AUC 过线，淡笔画不达标 |
| 夹具拟合逻辑回归 → 真实页 | 0.7210 | 52.73% | 48.00% | — | **不可用**（见“合成/真实分开”） |

- **秩融合（rank fusion）比线性融合稳定**：把两个信号的页内秩加权，避免了一个信号被另一个的尺度吞掉；
  最好的两个固定权重方案都达标本轮目标。
- **LOO 逻辑回归的失败有信息量**：它把权重放在 `blur4`（0.84–1.25）和 `blur0.8`（0.45–0.54）上，
  在“真值 vs 灰痕”的分类目标上确实更会分，但**淡笔画的低分尾巴被一起压掉**（45.6%）。
  目标是三个数，不是 AUC——这条曲线用 AUC 单指标选会选错。

## C. 输入归一化（改平面，再跑 context-v2，权重不动）

| 变体 | AUC | AUC（淡 vs 灰） | faint@71.48 | ghost@71.48 | ghost@95 |
|---|---:|---:|---:|---:|---:|
| 原始三平面 | 0.7081 | 0.5339 | 52.45% | 40.40% | 8.9% |
| 大核背景 101px 重算 ink | 0.7127 | 0.5453 | 52.21% | 42.49% | 10.3% |
| 滑窗对立化（31px 均值/标准差） | 0.5740 | 0.3609 | 55.24% | 29.88% | 7.3% |
| **plane0 = blur2** | **0.8202** | **0.7482** | 47.88% | 65.83% | 9.2% |
| plane0 = blur4 | 0.8185 | 0.7674 | 47.68% | 67.86% | 7.3% |
| plane0 = max(ink, blur2) | 0.7543 | 0.6263 | 50.73% | 46.60% | 9.9% |
| plane0 = blur2 + 每页全 CDF 分位 | **0.8202** | 0.7482 | **57.53%** | **68.03%** | 28.2% |

- **只换 plane0 就把 AUC 从 0.708 提到 0.820**，而且淡笔画-对-灰痕的排序 AUC 从 0.534 到 0.748：
  这是本轮唯一一条“排序能力本身变好”的改动（其余达标方案都靠它或它的融合）。
- 但它的同保护点淡笔画反而掉到 47.9%：**排序更好≠同保护点更好**，因为 pooled 阈值被各页尺度差异拖歪。
  补上每页分位映射后 57.5%——**两件事必须一起做**。
- 大核背景（101px）几乎没用；把 ink 换成“局部对立化”直接崩（0.574）：31px 窗口把纸面纹理也当信号放大了。
- `max(ink, blur2)` 介于两者之间（0.754），说明“保留锐利平面的深核心”并不能救回排序，反而把噪声带回来。

## D. 多尺度幅度门控

| 信号 | AUC | faint@71.48 | ghost@71.48 |
|---|---:|---:|---:|
| blur4 80% 分位硬门 × blur2 | 0.8093 | 45.61% | 62.36% |
| blur0.8/2/4 几何均值 | 0.8043 | 44.96% | 59.43% |
| 三尺度取 min | 0.7837 | 44.88% | 50.03% |
| blur2（单尺度参照） | 0.8060 | 45.19% | 61.65% |

- 硬门控（0.809）比单尺度（0.806）只多 0.003 AUC，且淡笔画没有改善；几何均值与取 min 都更差。
  **多尺度幅度门控在本轮没有独立价值**：平滑幅度里的判别信息基本被 σ=2 一个尺度拿走了，
  再往上加尺度只是把“灰雾平滑”这一件事重复算了几遍。
- 与归因文档一致：`blur4` 的 faint-vs-ghost AUC（0.717）确实最高，但它对**淡笔画低分尾巴**更狠，
  单靠它做门只会把淡字换成灰痕。

| 0.7081 / 0.8060 / 0.8202 / 0.8246 | 20 页真实页 AUC（精确秩 AUC） | 阈值无关，可跨页比较；仍是代理掩膜 |
| 52.45 / 57.53 / 68.03 | 20 页真实页同保护点 | 代理掩膜 + 公开 DocUNet，不是机主手机 |

关键事实：**在生成器域里 context-v2 几乎是完美的（0.978），任何把锐利平面换掉的改动都会掉到 0.67–0.72。**
所以“这套修复”不是普遍改进，而是**对真实相机照片的失真补偿**。这也解释了为什么夹具拟合的权重（几乎全压在
rank_s0 上，+0.5 给 rank_blur0.8）搬到真实页只到 0.721——它在合成域里没有失败可修，自然学不到真实域的修法。

## 过拟合与无泄漏检查

| 检查 | 结果 | 判断 |
|---|---|---|
| 推荐方案是否拟合了权重 | 没有（每页秩映射 = 经验 CDF） | 无参数可过拟合 |
| LOO 选权是否稳定 | `c+局部幅度` 17/20 折 (0.3,0.7)、3 折 (0.4,0.6)；`s0+blur4` 15/20 折 (0.3,0.7)、4 折 (0.4,0.6)、1 折 (0,1) | 稳定 |
| LOO 选出的“最优”是不是 c 平面单独 | 是：`c 平面+blur2` 的权重网格 20/20 折都选 (1.0, 0.0) | 与推荐方案一致 |
| LOO 版与固定 50/50 的差 | 0.8202 vs 0.8242（AUC −0.004），faint +3.7pp | 选型乐观度小，且方向不是“越拟合越好” |
| 19 页真实标签训练 | AUC 0.809 / faint 45.59% / ghost 58.47% | 有真标签也过不了淡笔画下限 |
| 夹具训练搬真实页 | AUC 0.721 / 52.73% / 48.00% | **不迁移**；无标签路径在这个域不存在 |
| 静默泄漏风险 | 纸面统计只用照片 ink，不碰扫描；秩映射用全页像素，不用掩膜 | 无监督可复核 |
| 捷径信号 | 密度 0.725、到墨迹距离 0.669，均未进推荐 | 已排除 |

**结论：达标方案不是过拟合出来的，但它是“在 20 页上看过之后选的”**——选型乐观度的量级由“LOO 版 vs 固定版差 0.004 AUC”
给出。真正需要新的留出集（机主手机拍摄）才能定论，本轮没有。

## 被否决 / 被排除的做法（如实记录）

- **滑窗局部标准化**（65px / 129px）：把区域偏置当信号，灰痕清理掉到 31% / 43%；局部对立化（31px）把 AUC 打到 0.574。
- **大核背景重算 ink（101px）**：AUC 0.7127，几乎等于不改。
- **把 ink 换成 max(ink, blur2)**：0.754，噪声回来了。
- **多尺度几何均值 / 取 min / 硬门**：都没有超过单尺度 blur2 的实质收益（≤0.003 AUC）。
- **纸面 CDF 作参照集**：在“满页淡字”的页上失准（50.16% vs 全页 CDF 的 57.53%）。
- **墨迹密度 / 到墨迹距离**：AUC 0.725 / 0.669，但读的是灰痕掩膜的 31px 隔离定义，**不采用**。
- **把 c 平面直接全局替换 context-v2**：合成侧 0.978 → 0.697，风险不可接受。

## 失败与限制

- **第 24 页没有任何候选修好**：AUC 0.32、灰痕 11.8%（基线 13.9%），且它占汇总淡笔画 46%。
  汇总与剔除两套数字都报；推荐方案剔除第 24 页后是 57.4% / 79.6%。
- **掩膜仍是代理**：真值来自平板扫描、淡笔画与灰痕都靠阈值定义；灰痕带混透印、纹理、照明与配准误差。
- **同保护点是单点**：71.48% 只是归档 context-v2 的操作点；换一个正面保留目标，三个数的排序可能变。
- **域门控没有实现**：只给了“σ 与增益 Spearman 0.31–0.33”的弱相关；具体门控规则（用什么阈值、在哪个环节判域）未验证。
- **只测了 context-v2**：c 平面替换没有配 537 探针、ghost-v1/v2 复测；也没有在应用真实管线（`ink_map` → 分数 → 掩膜 → 渲染）里端到端验证。
- **合成侧口径与归档不完全同**：逐夹具平均 vs 跨夹具 pooling，差异已在 `synthetic.json` 两个块里都给出。
- **AUC 的“页均”会被少数页拉低**：min 0.29–0.32（第 24 页），max 1.00；报告了范围，避免只看均值。
- **没有相机噪声模型**：纸面 σ 只是 ink 平面上的稳健散布，不等于传感器噪声。

## 是否值得进产品、进哪一层

**值得，但要分两级，且只进“分数层”。**

1. **先上“每页全 CDF 分位映射”（零参数、零域风险）。**
   位置：增强器里 context-v2 分数 → 二值/软掩膜的映射处（`score` 到 `mask` 之间），不是模型、不是渲染。
   收益（同保护点）：淡笔画 +3.0pp、灰痕 +6.5pp；逐页 AUC 不变（定义上），所以不会伤害“谁该留”。
   代价：需要一次全页直方图（1.4M 像素的一次排序或 256 bin 直方图，~ms 级），内存一个页级 CDF。
   风险：分位映射把“绝对分数”变成“页内相对分数”，对**极暗/极亮**页的行为需要上机确认（本轮只测 20 页公开照片）。

2. **再上“c 平面（blur2 打头）+ 分位映射”，但必须域门控。**
   位置：同一层，但作为**分支**：仅当判定为低质/灰雾拍摄时替换 plane0。
   收益：AUC 0.708 → 0.820，淡 52.45 → 57.53，灰 40.40 → 68.03（同保护点）。
   风险：合成域里同一改动把 AUC 从 0.978 打到 0.697；**在干净拍摄上直接启用会退化**。
   门控候选：纸面 σ（本轮 0.0076–0.0284）、锐利平面淡笔画 SNR（−0.16–1.45）、或直接把两个分数的分歧度当门。
   这些**都还没验证**，进产品前需要一个“干净 vs 灰雾”的实拍小集。

**不要做的**：扩模型（oracle 95.63% 说明容量不是瓶颈，本轮 AUC 提升也全部来自特征/分数层）；
用真值标签训练这个映射（19 页 LOO 监督融合反而不达标，而且产品端拿不到扫描真值）。
