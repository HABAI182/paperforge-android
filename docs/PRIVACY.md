# 隐私与数据

PaperForge为个人本地工具，不提供PaperForge账户、广告或自建分析后台。完整功能版内置Office、特殊格式和联网工具，声明INTERNET与ACCESS_NETWORK_STATE权限；更新、局域网传输和自定义服务由用户主动操作，不在后台定时检查更新或自动上传文档。历史模块化离线主包仍显式移除网络权限。Camera权限只在进入拍摄时请求，导入/导出使用系统文件选择器。

原图、编辑参数、OCR 文字和 PDF 工作副本在应用私有存储中。关闭应用不会清空草稿。系统自动云备份关闭。卸载会删除私有数据；另存到系统文档目录的文件由用户自行管理。

ML Kit 输入图像和识别结果在设备上处理。该SDK包含性能指标/模型更新通信能力。模块化离线主包通过移除网络权限阻止其联网；完整功能版允许语言包等网络能力，SDK模型下载及运行指标依其条款处理，不宣称完整包绝无网络通信。SDK 条款：https://developers.google.com/ml-kit/terms 。没有将 Google SDK 模型误列为开源模型。

分享会将选定输出复制至私有 cache/share，经 FileProvider 只授予所选接收应用读取该 Uri 的权限；实际接收应用由系统分享面板中的用户选择。缓存可能留至系统清理/卸载，当前版本不宣称安全擦除。PDF 文件在系统提供程序中的保存与同步行为取决于用户所选提供程序。

文档可移入回收站，也可明确确认后直接永久删除；永久删除清除私有文档目录和无其它文档引用的导出 PDF，不删除导入来源。批注草稿和保存的签名保存在本机。离线 ZIP 备份包含文档、OCR 和编辑历史，默认没有加密，请自行选择保存位置。PDF 可设置打开密码；应用内工作副本仍可编辑，不构成加密文件库。密码不持久保存；应用不主动记录文档文本、内容或密码。


Office排版在手机本机独立进程运行。完整功能版内置该进程，历史模块化发行使用独立Office APK。输入以临时副本交给引擎，结果返回主任务；结束时清理临时资源，中断残留由后续任务清理。手机表格、结构DOCX与PPTX不经过电脑或公共在线服务。

完整功能版直接提供更新、传输和智能工具入口。设置中的“检查更新”由用户点击后查询并显示版本状态；下载由用户另行选择，校验后再交给Android系统安装器确认；不定时检查或静默安装。新装完整包默认正式版渠道，原有选择保留。局域网服务默认关闭；历史模块化联网工具为独立APK，默认关闭更新。用户手动开启局域网时，仅显式选择的文件副本向已配对设备提供；HTTP链路未加密。配对token仅保存摘要，可撤销设备；服务关闭撤销当前二维码，队列与断点留在工具私有目录。文件选择不读取整库，移除副本不删除来源。更新只向配置的GitHub库查询；访问凭据经AndroidKeyStore加密，安装前完整签名与SHA核对。私有仓库需自行配置只读凭据，公开仓库无需凭据；APK不内置所有者令牌。

完整功能版的本地智能工具可直接进入使用，历史独立联网工具默认关闭智能功能；原文须从阅读/扫描界面选择页码或粘贴，工具只接收冻结的文字快照。语言模型下载由用户手动发起，ML Kit翻译在本机处理；该SDK的模型下载/运行指标依其条款处理。自定义局域网/BYOK服务仅在点击运行后接收本次选定文字与问题，密钥在工具中加密保存；服务方的数据处理由用户所选地址决定。结果、来源快照和历史保存在当前安装身份的私有目录（旧独立工具与完整包各自保存），原始OCR与PDF不被改写；导出Markdown包含来源文字。
