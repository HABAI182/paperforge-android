# 隐私与数据

主应用为非商用本地工具，不提供账户、广告、分析后台或文档上传接口。Manifest 显式移除 INTERNET 与 ACCESS_NETWORK_STATE 权限；Camera 权限只在进入拍摄界面时请求。导入/导出使用系统文件选择器，不申请全盘或相册遍历权限。

原图、编辑参数、OCR 文字和 PDF 工作副本在应用私有存储中。关闭应用不会清空草稿。系统自动云备份关闭。卸载会删除私有数据；另存到系统文档目录的文件由用户自行管理。

ML Kit 输入图像和识别结果在设备上处理。该 SDK 通常包含性能指标/模型更新通信能力，本应用通过移除网络权限阻止其联网。SDK 条款：https://developers.google.com/ml-kit/terms 。没有将 Google SDK 模型误列为开源模型。

分享会将选定输出复制至私有 cache/share，经 FileProvider 只授予所选接收应用读取该 Uri 的权限；实际接收应用由系统分享面板中的用户选择。缓存可能留至系统清理/卸载，当前版本不宣称安全擦除。PDF 文件在系统提供程序中的保存与同步行为取决于用户所选提供程序。

删除文档先移入回收站；永久删除才清除私有文档目录和无其它文档引用的导出 PDF，不删除导入来源。批注草稿和保存的签名保存在本机。离线 ZIP 备份包含文档、OCR 和编辑历史，默认没有加密，请自行选择保存位置。PDF 可设置打开密码；应用内工作副本仍可编辑，不构成加密文件库。密码不持久保存；应用不主动记录文档文本、内容或密码。


0.6.0：Office 手机引擎在独立 Android 本地模块中运行，同样没有 INTERNET 权限。转换输入复制到引擎缓存，转换结束删除该临时输入；结果自动复制回纸匠后尝试移除引擎临时结果。超过24小时的旧任务缓存会在下一次转换前清理。手机表格、结构DOCX与PPTX不经过电脑或公共在线服务。

可选联网工具为独立APK，默认不启用更新和局域网服务。用户手动开启局域网时，仅显式选择的文件副本向已配对设备提供；HTTP链路未加密。配对token仅保存摘要，可撤销设备；服务关闭撤销当前二维码，队列与断点留在工具私有目录。文件选择不读取整库，移除副本不删除来源。更新只向配置的GitHub库查询；访问凭据经AndroidKeyStore加密，安装前完整签名与SHA核对，系统安装仍由用户操作。
