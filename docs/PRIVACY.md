# 隐私与数据

本版本为非商用本地工具，不提供账户、广告、分析后台或文档上传接口。Manifest 显式移除 INTERNET 与 ACCESS_NETWORK_STATE 权限；Camera 权限只在进入拍摄界面时请求。导入/导出使用系统文件选择器，不申请全盘或相册遍历权限。

原图、编辑参数、OCR 文字和 PDF 工作副本在应用私有存储中。关闭应用不会清空草稿。系统自动云备份关闭。卸载会删除私有数据；另存到系统文档目录的文件由用户自行管理。

ML Kit 输入图像和识别结果在设备上处理。该 SDK 通常包含性能指标/模型更新通信能力，本应用通过移除网络权限阻止其联网。SDK 条款：https://developers.google.com/ml-kit/terms 。没有将 Google SDK 模型误列为开源模型。

分享会将选定输出复制至私有 cache/share，经 FileProvider 只授予所选接收应用读取该 Uri 的权限；实际接收应用由系统分享面板中的用户选择。缓存可能留至系统清理/卸载，当前版本不宣称安全擦除。PDF 文件在系统提供程序中的保存与同步行为取决于用户所选提供程序。

删除本地文档只涉及本应用副本及其草稿原图，不删除导入来源。此版本没有回收站或加密文件库；敏感内容可在导出后删除本地草稿。应用没有在日志中主动记录文档文本、内容或密码。
