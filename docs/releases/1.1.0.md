# 1.1.0

PaperForge 1.1.0 · 扫描增强、PDF 处理与完整包优化

下载 **PaperForge-1.1.0-full-arm64-v8a.apk**，Android 8.0+ / ARM64，一个 APK 包含全部引擎，可覆盖更新并保留文档。

- 柔和黑白增强，保留淡字和铅笔笔画。
- PDF 按页增强扫描图像，保留文字、矢量与表单。
- 设置新增可搜索的离线使用说明。
- HTTPS 局域网互传、证书身份核对与会话保护。
- 无障碍裁切、大字体布局及旋转/折叠后的草稿和阅读状态保留。
- R8 裁剪、字体去重、模型压缩，完整包约156 MB。

本版本整合 Issues #12、#13、#14、#4、#8、#11。相关功能已在前一轮完成验证；本次版本发布按要求不重复运行功能测试，仅重新构建并核对版本、签名、架构与摘要。运行验证使用 API35 x86_64 模拟器，ARM64 包已核对原生载荷；未进行真机与实体手势复测。

release-manifest.json、SHA256SUMS.txt 为校验资料，无需安装。历史版本保留。
