# 1.0.1

PaperForge 1.0.1 · 阅读与分区界面

下载 **`PaperForge-1.0.1-full-arm64-v8a.apk`**，**177.13 MB**，只需一个APK。Android8.0+ / 64位ARM手机，可覆盖原主应用并保留文档。个人非营利项目，无账户、广告、水印或订阅。

- PDF底栏精简为**视图、页面、批注、工具**；全屏、左右翻页、连续滚动、适页/适宽与纸张显示集中到明显的视图入口。目录、书签、朗读和翻译按分类进入。
- 格式转换、PDF工具、设置和阅读视图沿用分块卡片，增加第二层用途分类。卡片同排等高，子页可返回父级，文档布局入口直接显示，PaperForge主标题加大。
- 常用工具预设**压缩、识字、转图片、转Word**。升级只补全空列表，已有自定义列表保留，之后仍可自行增减或清空。
- 一键更新改为**检查更新**，明确显示最新版本、发现新版或连接失败；不把无适配架构误报为最新。发现新版后由你决定下载，核对后交给Android系统安装器确认。
- **六种外观、八种主题色**：跟随系统、明亮、深色、纯黑、暖纸、午夜蓝；墨绿、海蓝、鸢紫、琥珀、青碧、玫瑰、岩灰、咖啡。系统明暗与主题色分开，文档/阅读/更新/连接页面共享配色。
- Office、特殊格式和联网能力全部内置；保留指定绿色叠纸图标、扫描PDF默认不OCR及用户设置。

`release-manifest.json`和`SHA256SUMS.txt`是核对文件，无需安装。历史1.0.0保留。源码与下载公开后可免令牌访问，自定义私有仓库仍可配置只读凭据。

本轮只对改动做集中验证：阅读与分组导航、常用工具、全屏/视图、系统明暗和跨页面配色、200%字号，以及一个本地HTTP设备测试中的最新/新版/服务器不可用/架构不适配。未重复运行未改动的扫描和原生转换算法套件。ARM64正式包的签名、单架构和16KiB对齐已核对。
