# 纸匠 PaperForge 0.6.0 · 手机本地阅读与转换

阅读器现可左右翻页、全屏，重新进入会恢复页码、缩放和布局。首页、工具搜索与独立转换中心更紧凑。

这版新增文字转PDF、JPG/PNG/WebP互转、PDF分段长图，以及手机本地表格XLSX/CSV、结构Word和整页图片PPTX。Office排版转换由一次安装的手机引擎完成，结果自动返回纸匠，不需要电脑或上传文件。

## 安装

1. 普通手机安装 `PaperForge-0.6.0-arm64-debug.apk`；已有旧版可覆盖安装，签名保持一致。
2. 使用 Word/Excel/PowerPoint/ODF 排版转换时，再安装 `PaperForge-Office-Engine-0.6.0-arm64-debug.apk`。
3. 在转换中心选择格式与文件。表格可先校正；Office结果可直接预览、分享或另存。

x86_64包用于相应设备/模拟器；主应用通用包包含arm64与x86_64。预发布版本仍使用原有开发签名。旧tag和附件保留。

## 验证与范围

8个聚焦Android检查、真实手机引擎交接和阅读进度强停恢复已完成；表格、DOCX、PPTX结果经独立解析器读取。交互环境为API35 x86_64模拟器，未做实体ARM64手机验收，也未重跑扫描全量语料。

Office排版受字体与复杂对象影响；PDF结构重建不保证恢复原始Office结构。PPTX为整页图片模式。完整研究计划含98卡，逐卡状态保留，未把远期研究能力标成全部完成。
