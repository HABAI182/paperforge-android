# 2.1.1

PaperForge 2.1.1 · 处理更快、导入更稳

下载 **PaperForge-2.1.1-full-arm64-v8a.apk**，Android 8.0+ / ARM64，一个 APK 包含全部功能，可直接覆盖 2.1.0 安装，文档、设置和备份都会保留。

- 更快，结果不变：页面处理提速，扫描结果与 2.1.0 逐像素相同；OnePlus Ace 5 上一次导入 14 张照片约快 10%。
- 相册导入：读不出的照片跳过并列出，不再中断整批；显示“正在导入图片 i/N”；可随时取消，已导入的页面保留。
- 缩略图：页面网格和缩略图条缓存缩略图，来回滚动不再重复生成，卡片高度不再跳动。
- 处理失败可重试：照片过大导致内存不足时任务标为失败并保留原图，可在任务中心重试，不再一直显示“处理中”。

完整内容见[更新记录](https://github.com/HABAI182/paperforge-android/blob/main/CHANGELOG.md)。

release-manifest.json、SHA256SUMS.txt 为校验资料，无需安装；APK 的 SHA-256 与字节数见 SHA256SUMS.txt 和发布页。历史版本保留。
