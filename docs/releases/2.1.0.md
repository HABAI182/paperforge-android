# 2.1.0

PaperForge 2.1.0 · 扫描画质、PDF 文字编辑、去水印与字体

下载 **PaperForge-2.1.0-full-arm64-v8a.apk**，Android 8.0+ / ARM64，一个 APK 包含全部功能，可直接覆盖 2.0.1 安装，文档、设置和备份都会保留。

- 书页展平更准：页边手写批注、短代码行和分数行不再把旁边的印刷文字扭斜。
- 纸面处理：透过纸背的线条不再当作横线保留；小号印刷字和 ①② 这类孤立符号保留更完整。
- PDF 文字编辑：在页面上直接选字编辑；字体缺字时只补缺的字，其余保持原字体；字体面板停靠在页面下方，实时预览。
- 字体管理：63 种开放许可字体按需下载，9 个下载源自动选用可用的。
- 去水印：更多扫描应用印章、Word 页眉水印和图片水印；预览快速切换不再闪退，原图不再偏黄。
- 文档库：“已编辑”“已去水印”等状态标签；完整文件名可查看和复制。

完整内容与已知限制见[更新记录](https://github.com/HABAI182/paperforge-android/blob/main/CHANGELOG.md)。

release-manifest.json、SHA256SUMS.txt 为校验资料，无需安装；APK 的 SHA-256 与字节数见 SHA256SUMS.txt 和发布页。历史版本保留。
