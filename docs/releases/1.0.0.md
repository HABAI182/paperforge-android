PaperForge 1.0.0 完整功能版 · 界面整理修订

下载 **`PaperForge-1.0.0-full-arm64-v8a.apk`**，仅需一个安装包，**177.12 MB**。版本码10003，可覆盖原主应用并保留文档。个人非营利项目，无账户、广告、水印或订阅。

- 主导航统一为**文档 / 工作台 / 设置**。文档保留最近、全部、收藏、搜索、导入、多选、扫描和固定回收站；详细筛选与布局按需展开。
- 工作台按**扫描与识字、格式转换、PDF工具、文档整理、任务与流程、连接与智能**六类组织。转换继续按格式族分区，搜索可跨分类查找，最多四个常用快捷入口；菜单统一固定与能力说明。
- 设置按主题进入，顶部直接提供**一键更新**和**GitHub项目**。一键更新执行检查、下载与核对，再打开Android系统安装器；系统确认仍由你完成。新装完整包默认正式版渠道，已有偏好保留。
- 统一卡片、留白和文字层级；普通字号双列分类，窄屏与大字号改用紧凑横向卡片。工具、工作流与存储返回进入时的分类。
- Office、特殊格式和联网工具全部内置，桌面只保留一个图标；系统分享面板可直接分享到PaperForge传输。
- 保留指定绿色叠纸标志、扫描后大画布/左右翻页/缩放/全屏、继续阅读。默认85%增强、零倒计时连拍、PDF不做OCR、原比例纸张和90%导出质量，旧设置不重置。

`release-manifest.json`和`SHA256SUMS.txt`是核对文件，无需安装。扫描、OCR和文档转换在手机运行；翻译首次需下载语言包，可选模型按需导入，远程服务由你主动运行。私有仓库更新需自行配置只读令牌，仓库公开后可免令牌。

本轮完成两种架构正式构建、针对性UI/导航/大字号/系统分享检查、GitHub入口和一键更新发起及断网提示检查；未重复运行未修改的扫描与原生转换算法套件。下载/安装延续已有校验链路，本轮离线模拟器未执行远端新版本实际安装。ARM64签名、架构和16KiB对齐以附件清单为准。
