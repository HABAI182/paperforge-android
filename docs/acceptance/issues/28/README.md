# #28 · 分享即处理与去水印

实现见 `PdfWatermarks`（对象级水印）与 `ShareEnhance`（分享流水线）。样本为用户私人文档，**仅存于设备 `files/samples`，不进仓库**。

## 已完成

- 分享 PDF → 读取缓存副本 → 去水印（可关）→ 压缩（可关）→ 微信/系统面板转发；原件不进入文档库
- 极简进度窗（半透明 Dialog + 阶段文案）
- 设置 → 导出与文件名：分享处理、去水印、压缩、转发目标四项
- 图片水印：重复小图哈希 + 角落位置识别，删除 `Do` 操作并清空 `/Resources`/`/XObject` 条目
- 文字水印：token 级删除（解析内容流、按 `Tf` 字体解码 `Tj` 字符串、归一化比对），解码失败才退回遮盖

2. 第一版删除资源时作用在 `PDResources` 包装对象上未落盘，清理后仍数到 2 张图；改为直接操作页面 COS 字典 `/Resources → /XObject` 后，回读为 1 张。
3. 一次外部回读误用 PowerShell 文本重定向拉取二进制，导致“文件损坏”误判；改用 `cmd /c` 二进制重定向后确认结果。

## 范围决定

图片分享（`SEND_MULTIPLE image/*`）本轮不接入去水印流水线，仍按导入处理。原因：当前水印识别是 PDF 对象级（重复小图 + 角落短文本），图片没有对象层，需要平铺/角落栅格检测与修复，属于独立工作量；先把 PDF 路径做实、标注清楚，避免用半成品栅格去水印冒充可用。此项保留为 #28 后续。
