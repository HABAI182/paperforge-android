### 同图对照与差距

处理对象为 3 张机主真实照片，参考为逐页配对的成品 PDF。不是合成纸张，也不是本机 CameraX 实拍验收。独立分支的默认自动页框仍有较大差距：

| 样本 | 近似页框 IoU | 平均角误差 | 占图像对角线 | 第二轮黑白配准 MAE（0–255） |
|---|---:|---:|---:|---:|
| notes-1 | 0.7131 | 174.21 px | 8.17% | 16.44 |
| notes-2 | 0.7950 | 153.69 px | 7.21% | 18.08 |
| notes-3 | 0.4772 | 316.51 px | 14.84% | 20.63 |

四角为人工近似标注，估计不确定度 ±15 px；配准 MAE、覆盖率与墨迹召回/精确率均为代理指标，不代表文字正确率。完整数值见 [配对指标](behavioral-metrics.json)。第一轮黑白配准 MAE 为 16.66 / 19.68 / 24.63，第二轮有所下降，但部分墨迹召回下降，不能据此宣布整体质量更好；第二轮同时调整墨色缓冲与斜率补偿，也不能将差异归因于单个算法。

私有对照图与完整结果在仓库外 `work/behavioral-v1/`、`work/behavioral-v2/`。自动裁切与人工四角隔离诊断分别标为 `refined`、`refined-isolation`，不得混记。参考页与我们的各滤镜并排，失败裁切同样保留。图像已经过视觉查看：独立自动裁切仍会带入键盘/桌面；书脊附近的非二次曲率、透印和墨色也未完全接近参考。原有引擎继续作为默认。

1. 先固定增强和展开，研究语义候选的置信度口径：此批 DocQuad 的角点分数为 0.106 / 0.492 / 0.121，前两张的候选四角可用却被当前 0.55 门槛丢弃，第三张则是错误窄条。应将页形/边缘证据与角点分数分开校准，并加入键盘、空桌面等负例，不直接整体降低自动拍摄门槛。
