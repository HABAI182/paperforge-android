## 2026-11-01：保留现有引擎，优化真实纸面

以上较低的 IoU 属于**可选独立引擎**，不代表默认链路。同样的三张照片，默认 HYBRID 原有模型的 IoU 为 0.9726 / 0.9736 / 0.9828，平均角误差 13.92 / 17.43 / 6.75 px（人工标注不确定度约 ±15 px）。现有模型与默认链路继续保留，不因试验引擎而替换。

练习册增强新增局部纸面估计：小尺度膨胀＋中值背景场消除灰底和突变投影，再使用连续墨色曲线抑制透页；细线高频与邻近墨迹保护前景淡字。此前的大尺度亮场方案在锐利投影附近有黑晕，已改用中值场，不用裁掉阴影区域的办法处理，避免切掉真实公式。强度为零仍保留原始灰度。参数集中于 `scan_params.json`，旧增强路径可通过参数回退。

编辑器练习册调节增加“淡字保留”，实时预览，按页存入现有处理元数据；保存、撤销、导出和应用全部复用原有页面机制。应用全部仅复制调节值，不复制其他页的图像/OCR 资源。

## #26：票据来源和明细

提取时保留页号、行号、原文、真实 OCR 置信度/引擎、坐标、页面标识和几何签名。扫描件复用校正后的 OCR；PDF 复用原生文本/离线 OCR 的实际区域。点字段来源可看整页位置或放大字段；缺少坐标只展示整页，不造定位，裁切发生变化则提示重新提取。

核对表增加币种、可折叠的明细编辑，以及明细合计与票面金额的差额提示。币种只来自实际符号/代码；单独 `$` / `¥` 保留原符号，不猜测国家。保守解析明确的明细行，未识别字段留空。规则完整度与识别置信度分开显示。

CSV 保留原有列顺序，并增加币种、明细、字段来源和文档标识；旧八列账本原子升级、不丢历史行/前导零。XLSX 增加“明细”子表，数量、单价、金额为数值，来源可溯源。同一文档的同一记录不重复追加，人工无来源记录仍允许单独追加。确认前不写入账本。
