# #13 · 已有扫描 PDF 二次增强

入口：阅读器「工具 → 优化与属性 → 图像增强」，或工具搜索「增强」。阅读器仍保留「视图、页面、批注、工具」四个底栏入口。

- 自动、柔和黑白、灰度、清晰、去阴影五种预设，直接复用扫描的 `EnhancePipeline`。
- 当前页、选页、整篇；对所选页中的一页切换原图/增强后预览。
- 只替换占页面较大比例（至少 35%）的扫描图像资源；页面指令、原生及 OCR 文字层、矢量、裁切框、旋转、批注和表单保留。
- 页面资源及嵌套 Form XObject 按需独立复制，不改变其它页面共用的原图。绝不整页栅格化。
- 支持旧黑白位图、普通图像和已验证全白蒙版的无损扫描图。小图标、内联图片、真正透明/带显式遮罩的图像保留。无扫描底图的页跳过；全部无可处理图像时给出原因。
- 数字签名文件在处理前提示并停止，避免生成无效签名。普通批注与表单的保留方式在界面说明。
- 任务内存预算限制解码采样；较大图像可能降采样，界面提前说明。页尺寸不变。
- 后台任务共用进度、取消、结果登记和失败恢复。处理后的 PNG 阶段带来源/参数签名和 SHA-256 校验，重试复用已完成阶段。最终 PDF 先保存、重新打开核验及同步，再提交文件。
