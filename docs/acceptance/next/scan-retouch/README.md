# 本地扫描清理与修复实验

2026-10-28，开发候选，保留大版本发布暂停。

编辑页“增强”面板和“更多”都有“清理与修复”入口。支持涂抹/擦除、点选、撤销/清空、强度、原图对照、全屏浏览与双指缩放。草稿绑定当前页面外观并作为资源随备份保留；完成后另存扫描文档，来源关系与冻结原图一起保存，原件不覆盖。任务记录包含输入快照、配方、模型指纹、校验过的结果检查点与可重映射的结果文档 ID。

## 实际算法

- 局部修补：OpenCV Telea；彩色笔迹：仅在选区内筛选明显彩色像素后修补，黑色手写可手动涂抹后用修补/智能填补。
- 智能填补：官方 [MI-GAN](https://github.com/Picsart-AI-Research/MI-GAN/tree/2b793c5ece43f4253e32d4afc257120a5deed6f5) pipeline v2，MIT，单独导入约 28 MB 权重。UINT8 RGB NCHW / 已知区域为255的掩码；工作区域加128像素上下文，最长边1024，再按选区与强度复合。它填补周围纹理，不恢复被遮住的真实文字。
- 去噪：OpenCV 彩色 NLM，256像素工作块和8像素上下文，块间取消/释放交互优先队列；空选区块不运行。不存在整页重复计算。
- 高光压制：Lab亮度通道上受限 CLAHE，仅影响仍有纹理的较亮区域，不宣称恢复过曝信息。
- 3×超分：官方 [ONNX Model Zoo Sub-Pixel CNN](https://github.com/onnx/models/tree/c5cae0f1942c8d7727372c7b1f6b485aa39e4421/validated/vision/super_resolution/sub_pixel_cnn_2016)，240,078字节，固定224输入、192中心步长和16像素上下文，输出最长边4096。亮度经过模型、颜色来自插值原图。可按原尺寸来源对照，不宣称通用文字无误。

固定来源、接口、版本与 SHA256 在 models.json；MIT/Apache完整许可同时随基础 APK 携带。基础 APK 没有联网权限，MI-GAN 下载由用户浏览器完成，应用只导入和离线推理。

## 本次验证

API35 AOSP x86_64，三个直接相关的检查共11.168秒通过。MI-GAN实际手机端推理、去噪/高光/修补的选区外像素改动均为0；完整选区中的模拟边缘遮挡填补结果在 repair-MIGAN.png。数独照片来自 OpenCV 4.12.0，源链接和SHA见 photo-source.json；它是真实公开纸张照片，不是机主拍摄。对其加入固定噪声的MSE由64.17降到19.52；这不是全部实拍噪声准确率。3×模型输出与插值有977367个不同像素，已查看大图，样张可见数字仍与来源对应；细字仍需逐件核对。photo-*.png保留所有对照。
