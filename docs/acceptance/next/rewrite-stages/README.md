# 原生编辑与压缩的阶段恢复

两项集中检查分别中断图片编码/体积搜索和第一页原生改字，然后更换workId续跑，保留既有检查点。压缩冷执行与恢复后的图像流相同；完整质量候选再次运行不重新编码。目标不可达时保留实际最小结果，不虚报达标。

原生页补丁只持久保存新字体与改写内容流，并在原文档上重新组合。先生成补丁再打开最终文档，避免同时持有两份完整PDF。三页共享约2.36MB随机图像，两页不同中文子集的补丁共7726字节；保留原生文字、链接及第三页。私有补丁容器不作为用户可阅读的PDF输出。

`independent-readback.json`由实际输出在独立MuPDF中读取，六页冷执行/恢复像素完全一致，未编辑页与原件也一致。源/结果样本由本次两项androidTest生成，未调用旧设备套件。完整中间PDF/ZIP的最终组合仍重做，不宣称原生调用在任意字节中途恢复。
