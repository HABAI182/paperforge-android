# UI 设计与页面规范

方向：**简约、舒展、清楚、有现代审美；让文档成为画面的主体。** 功能丰富通过层级和上下文承载，常用动作直接可达，高级能力逐级展开。

本文件中的布局与方案图是设计目标。实现可以分期，但视觉、命名和交互要使用同一套规则。

## 1. 当前界面诊断

结合当前源码及仓库留存截图：

- 首页大标题、宣传式扫描卡、六个快捷方块占了较多首屏，最近文档下沉，搜索也不在最先看到的位置。
- 最近与文档分页有重复内容，实际最近按修改时间；不能快速区分正在读、待整理、扫描草稿、已有 PDF。
- 编辑页文档名用大输入框长期占位，多行工具、滤镜、缩略图和导出共同争夺空间。
- 阅读器同时有顶栏、底栏和转换工具行；普通阅读也持续显示抽页、压缩等编辑功能。
- 主色是墨绿，部分选中/容器色仍使用默认紫调，深浅色槽未完整指定；视觉系统不统一。
- 多选已经具备，但选中状态、工具可用性、选择范围和退出后位置需要更连贯。
- 一些长任务用全局忙碌状态影响整个工作台；错误与加载合在一段说明中，用户不容易判断正在等还是已经失败。

这些是布局和代码审阅结论，不是本轮新装机实测。改版时保留现有可用功能，避免因“清爽”丢掉导出、直接删除等明确需求；Collabora 的官方修复记录就有 UI 改版期间 PDF 导出意外消失的例子。[OF09]

## 2. 信息架构

底部三个主要去处：**文档、工具、设置**。扫描是一个明确主操作，可以是带文字的浮动按钮或底栏中部独立动作，不把扫描混成一个永远没有内容的页面。

### 文档

顶部标题与导入/多选；其下固定搜索；快速筛选“最近、全部、收藏、未整理、文件夹”；下面是文档列表/网格。最近可切换“最近打开 / 最近修改”，默认最近打开，草稿另有轻量区分。文件夹与标签在列表筛选和侧面面板中展开。

### 工具

搜索工具 + 用户固定的 4–8 项 + 分类列表：扫描与增强、文件转换、页面整理、文字与表格、批注与表单、归档与自动化。用“转换为 Word”而不是一堆用户不熟悉的内部方法名。

### 设置

基础偏好与高级配置按目的分组：扫描、阅读、输出、外观、工作流、存储与备份、扩展引擎、关于。保留现有搜索和 JSON 导入导出；设置自动保存，具体参数说明靠近控件。

不设头像占位、会员入口、积分、推荐流、广告横幅或无人使用的团队入口。

## 3. 视觉变量

### 3.1 配色

默认选“纸白 + 石墨 + 墨绿”，低饱和背景、少量强调。颜色必须按语义角色定义，而不是散落在每个屏幕里。[UI03]

| 角色 | 浅色建议 | 深色建议 | 用途 |
| --- | --- | --- | --- |
| 背景 | #F7F8F5 | #111715 | 整页背景 |
| 主表面 | #FFFFFF | #18211D | 文档卡、面板 |
| 次表面 | #EEF2EC | #202B25 | 搜索、设置分组 |
| 主文字 | #1B2420 | #E8EEE8 | 标题/正文 |
| 次文字 | #59645D | #A9B7AD | 元信息 |
| 强调 | #176B54 | #8CD4B5 | 主动作/选中 |
| 强调容器 | #D7EEE3 | #244C3C | 选中项/小标签 |
| 分隔/轮廓 | #D9E0D9 | #3C4941 | 细分隔与边框 |
| 错误 | #B3261E | #FFB4AB | 真实错误，不用于普通疑问提示 |

这些是设计起点，落地时计算实际前景/背景对比并随组件状态调整。禁用态、遮罩、浮层、输入焦点和选择色也要成套定义。系统动态配色可选；启用后整套替换，不能只有主按钮变色。

可选强调色：墨绿、靛蓝、暖橙、紫灰；界面背景仍保持中性，不把所有卡片涂成高饱和彩色块。用户自定义颜色生成完整色阶，预览明暗两套。

### 3.2 字体与数字

使用系统中文无衬线，拉丁与数字保持一致；不捆绑很大的装饰字体。正文 14–16 sp、重要列表标题 16 sp、页面标题 22–28 sp、元信息 12–13 sp，中文行高约 1.35–1.5。关键文案不靠全大写英文装饰。

文件名最多两行，长名称在详情可完整查看；页数/文件大小/进度使用稳定数字宽度，状态更新不使按钮跳动。系统大字号优先，用户额外字号不能压扁系统无障碍缩放。

### 3.3 尺寸、圆角、阴影

间距以 4、8、12、16、24、32 dp 为主；手机外边距 16–20 dp，平板随内容列宽调整。图标 22–24 dp，触控区域至少 48×48 dp。卡片圆角 12–16 dp，底部面板 20–24 dp；不把每个控件都做成巨大胶囊。

主要依靠留白、细分隔和表面层次；阴影只给浮动层与悬浮主操作。图标用同一套线性/填充规则，文档类型图标不过分抢色。普通功能不靠 emoji 充当正式图标。

### 3.4 动效

轻量状态切换约 120–180 ms，面板/导航约 180–240 ms；避免繁复弹跳、光效与持续动画。滚动、缩放和纸框跟手优先。设置减少动效后关闭非必要动画；拍照缩略图可轻反馈，不能因为动效触发相机重绑。

## 4. 文档首页

首屏目标：马上能搜索、继续阅读、开始扫描或导入。顶部品牌不超过一行；不再用半屏解释“这是一个扫描软件”。

### 布局

1. 顶栏：纸匠 / 文档数量或当前文件夹，右侧导入与更多。
2. 搜索条：“搜索文件、文字或标签”，保持可见，点后进入统一搜索状态。
3. 筛选条：最近、全部、收藏、未整理，更多筛选展开。
4. 可选“继续阅读”单条卡，只在确有最近阅读时出现。
5. 文档列表：缩略图、标题、类型/页数/时间；右侧更多。草稿、处理中、待导出用轻状态，不写一堆技术信息。
6. 主操作：“扫描”按钮固定可达；导入在顶栏或主操作展开中。
7. 底部导航：文档、工具、设置。

### 列表规则

默认舒适列表，一屏能看到约 5–7 项，取决于字号；紧凑模式 7–10 项，触控高度仍足够。网格适合看封面和扫描缩略图。排序支持打开/修改/创建时间、名称、大小、页数，方向明确。

文件夹路径用面包屑，标签用短文本。搜索结果显示命中页/片段，不只返回文件名。输入清空后回到原筛选、原滚动位置。

### 多选

长按或“选择”进入；顶栏变“已选 N 项”，清楚显示当前范围。选中用同色浅容器 + 勾选，避免默认紫色混搭。底部显示分享、合并/转换、回收站、更多；直接删除保留在明确菜单中，用户也可固定到多选栏。

批量操作完成后能撤销的给撤销提示，不能撤销的只确认一次。切换筛选前明确结束/保留选择策略，不让屏外选择数量悄悄变动。

## 5. 相机

全屏取景，顶部只保留返回、闪光灯、自动/手动和更多；取景上方一条轻提示。底部模式条“文档 / 书籍 / 票据 / 证件 / 白板”，每次只显示当前模式的必要控制。

中部快门足够大，旁边是相册、已拍页数/缩略图和完成。缩放用 1×/可用倍率及捏合，曝光/对焦长按或点按后显示。不要默认放十几个滑杆覆盖取景。

纸框线条稳定、与主色一致。只有已经检测到候选时画实际框；无法识别时可拍整图，不能用“看似正确”的假框误导。状态用“可拍摄 / 自动拍摄中 / 已保存第3页”，尽量避免大段警告。

模糊/暗光/反光提示默认轻量，不拦手动快门；允许关闭提示。自动模式可以采用质量信号决定等待，但用户始终能拍。高级阈值、等待、分析频率继续可调，放设置而非主取景层。

## 6. 扫描编辑

文档名在顶栏显示，点名称才重命名；撤销/重做靠近编辑区域。画布占剩余空间的主体，缩略图条可收起。底部第一层是“裁切、增强、识字、更多”，导出作为明确主操作。

### 裁切

进入后画布最大化，底部显示自动、全图、比例、重置、完成；拖点时显示放大镜。模式内不再叠一排无关 PDF 工具。整边拖动、角点移动、外扩边距和书脊线有不同形状反馈。

### 增强

效果缩略图展示当前页面真实预览，名称用“自然、清晰、去阴影、黑白、彩色、白板”。选中效果后才展开强度/亮度/对比度。当前/所选/全部三种应用范围清楚；长按对照原图和显式对比按钮并存。

### 曲面与恢复

曲面、去手指等进入独立面板：原图/结果对照、强度、应用范围、重置和应用。高级模型处理有进度，可以取消；取消不改原件。没有处理成功不显示假的“完成”状态。

### 页面条

点缩略图切页，长按多选或重排；独立“页面管理”显示网格。补拍、替换、复制、移入另一文档和左右书页拆分有明确菜单，防止一排小图标全挤在画布上。

## 7. 阅读器

默认只留一条顶栏和可隐藏的轻底栏；页数胶囊靠下，点击跳页。工具显现时提供目录/缩略图、显示设置、批注、分享；转换和页面管理在更多中，也可固定为用户快捷项。

全屏时仅文档和短暂页码反馈。左右翻页采用简洁平移/吸附，不做影响阅读的卷纸拟物；动画可关闭。搜索条在需要时出现，搜索结果抽屉不遮住当前命中区域。

详细手势与状态见阅读专篇；UI 不得自作主张改变其返回顺序与缩放优先级。

## 8. 转换中心

标题“转换文件”；源卡片显示文件名/数量/格式；目标卡片显示大号目标格式和简短模式说明。下面是常用预设、范围、保存位置；高级参数折叠。主按钮命名“转为 PDF”“生成 Word”，不使用含糊的“执行”。

转换中显示阶段和取消，允许离开继续；完成页显示文件列表与打开/分享/查看位置。批量失败只占该项，不用一个全局错误抹掉全部成功结果。

保真/编辑说明靠近模式，不弹长篇通用免责声明。电脑引擎离线时显示等待电脑与本地替代路线。无引擎路线可列在“可扩展能力”中，但不可假装能点击运行。

## 9. 工具与搜索

工具页先给搜索和固定项，不默认滚动几十个等权方块。分类可折叠，显示常用中文词和支持文件类型；最近使用最多 4 项，允许隐藏。

工具搜索与文档全文搜索视觉上不同：前者找动作，后者找内容。工具详情默认只解释输入、结果和一两个必要参数。支持同义词：识字/OCR/提取文字，Word/DOCX，转照片/转图片。

上下文菜单只列当前对象适用动作。例如一张图片可以转 PDF/OCR/增强，不能同时显示“填写已有 PDF 表单”。用户已收藏的工具即使暂时不可用，也说明所缺输入，而不是突然消失。

## 10. 设置与高度自定义

采用目的分组和搜索，普通设置是开关/选择，数字参数显示当前值与单位。已有高级扫描参数继续保留，默认折叠。所有重要设置可恢复单组默认，而不必清空全部偏好。

配置档案建议：日常扫描、书籍、票据、阅读、高清归档、快速分享。档案是一套有名字的预设，可以复制、导入、导出、改名；覆盖哪些设置可见。不要一次切换“书籍”连主题色和所有全局快捷键也被改掉。

允许自定义：主题/强调色、紧凑度、字号、主页筛选与固定工具、阅读方式和手势、OCR速度档/语言、导出质量/命名/目录、扫描参数与配方。保留默认档案，防止调乱后无法恢复。

开发诊断、模型详情、原始置信度、日志导出收进高级页。它们可以帮助排错，但不出现在普通产品路径上。

## 11. 状态与反馈文案

| 状态 | 视觉/行为 | 文案方向 |
| --- | --- | --- |
| 空文档库 | 清楚的扫描与导入按钮，小插画可选 | “从扫描或导入开始” |
| 搜索无结果 | 保留查询与筛选，提供清筛选/识别未OCR页 | “没有找到，试试名称或正文中的词” |
| 加载文件 | 页面占位、实际阶段，取消可用 | “正在打开…” |
| 格式不支持 | 显示识别到的格式和可用替代 | “这类文件需要电脑转换引擎” |
| 文件权限失效 | 重新选择原文件 | “原文件已移动，重新定位即可继续” |
| 单页处理失败 | 页面保留，重试/跳过 | “第4页未处理完成，原图已保留” |
| 保存失败 | 保留本地完整输出，重选位置 | “写入目标位置失败，可换位置重试” |
| 操作完成 | 短提示+相关动作 | “已生成 PDF · 打开 · 分享” |
| 可撤销操作 | Snackbar 不盖按钮 | “已移入回收站 · 撤销” |

不用“未知错误”“操作异常”作为唯一说明；技术详情放可展开项。不要把所有错误都变成红色整页警告。

## 12. 快速可达要求

常用操作的设计目标，不含系统首次权限：

| 动作 | 目标操作数 |
| --- | --- |
| 打开扫描 | 1 |
| 继续上次阅读 | 1 |
| 开始搜索文档 | 1 |
| 导入文件 | 1–2，之后进入系统选择器 |
| 对当前页 OCR | 1–2 |
| 用上次预设导出 | 1–2 |
| 切换左右翻页 | 2 |
| 进入/退出全屏 | 1–2；退出有系统返回 |
| 长按进入多选 | 1 |
| 搜索任意工具 | 1–2 |

用真实流程计数，不能把一个“更多”里面嵌四层当作一项操作。常用动作可以固定，但第一次安装时默认就应好找。

## 13. 平板、折叠屏与大字号

按窗口可用宽度而非设备名称布局。窄屏单列；中等宽度可列表+预览；宽屏阅读可目录/正文/笔记，但默认先两栏，按需第三栏。[UI02]

边缘到边缘背景可以铺满，按钮内容避开刘海/系统导航。底栏背景不应被错误 inset 成两侧留缝；Toast/Snackbar 不盖快门、保存或删除按钮。键盘弹出时当前输入和确认可见。

系统大字号到 200% 时关键动作仍可达，允许工具栏换行/收进菜单，不把文字硬裁。色彩不是唯一状态标记；选择、错误、正在处理同时有图标/文字。触控目标不因紧凑模式低于可点范围。[UI01]

## 14. UI 改造的交付要求

1. 建立统一语义色板、字号、间距、圆角、图标和通用状态组件。
2. 每屏保留清楚的主动作，默认不超过 4–5 个同层工具；高级项进入上下文面板。
3. 首页、相机、扫描编辑、阅读、转换、页面管理、任务中心、设置采用一致导航与返回方式。
4. 改版前后列功能对照表，明确已有多选/直接删除/设置/备份/导出仍能找到。
5. 至少核对窄手机、深色、大字号和一处宽屏；只对改动关键交互做必要检查。
6. 方案图、实际截图、未实现入口在文档中分别标注，不以概念图充当交付证据。

方案应看起来安静、精致、可读；用户打开时先看到自己的文件和下一步动作，而不是产品自己在介绍自己。
