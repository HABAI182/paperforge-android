# 阅读模式与交互规范

这份规格落实“可以左右滑动翻页、可以全屏”的要求，并把阅读补成独立的日常能力。P0/P1 是近期开发范围，P2/P3 为后续扩展；本文件描述目标行为，没有声称这些功能已交付。

## 1. 当前问题与改造目标

当前 `ReaderScreen.kt` 用 `LazyColumn` 逐页显示固定最长边 1100 px 的位图，缓存上限 24 MiB，放大 1–4 倍主要是缩放已有位图。已有搜索命中、跳页和缩略图，缺少横向分页、全屏与文档级位置恢复。顶部、底部、额外工具行同时出现，阅读空间被持续占用。

新的阅读器必须先让人舒服地读，再让人调用编辑工具。阅读页面只默认保留返回、文件名、搜索、显示设置、更多；页面工具与转换放进按需面板。PDF Expert、Foxit、Xodo 的横向/纵向选择和隐藏工具方式可作为工作流参考。[RD01][RD02][RD03]

## 2. 阅读方式

| 模式 | 用户行为 | 默认/阶段 |
| --- | --- | --- |
| 横向单页 | 左滑下一页、右滑上一页，一次停在一页；适合书籍、资料 | 新增 P0；普通文档全局默认可选，首次保持纵向避免强改习惯 |
| 纵向连续 | 上下平滑滚动，页面间距统一；适合长材料和浏览 | 保留并优化 P0 |
| 纵向单页 | 上下滑动但逐页吸附，适合单手短页 | P2 |
| 横向双页 | 平板/横屏面对页，支持封面单独显示 | P1/P2 |
| 连续双页 | 宽屏双列连续浏览，可手动切回单页 | P2 |
| 右向左 | 翻页顺序反转，页号含义不变；适合特定书籍/漫画 | P2 |
| 文字重排 | 单栏可调字号的临时阅读视图，保留回到原页入口 | P2 |
| 演示 | 全屏单页、可设点击翻页、激光指示/自动播放可选 | P3 |

显示设置用一个底部面板，近期只显示“连续 / 左右翻页”“适宽 / 适页”“全屏”“记住本文件设置”。模式数量增长后分“布局、外观、手势、其他”四组，默认不展开高级项。

全局默认与文档覆盖分开。用户对某份横版 PDF 选了横向双页，不能让另一份竖版票据自动变成双页。提供“恢复全局设置”与“设为以后默认”。

## 3. 全屏与工具收起

### 3.1 两层状态

- **专注阅读**：收起应用顶栏/工具栏，保留系统状态栏，轻量页数提示可选。
- **全屏阅读**：应用栏与系统栏均收起；系统边缘手势可临时呼出系统栏；用户随时退出。[AN03]

二者都应有明确菜单项。单击页面中部默认切换应用工具显隐；选择文字、点击链接、拖动批注、滑页后不顺带触发显隐。第一次进入全屏可显示一次短提示“轻点中部显示工具”，之后不反复教学。

### 3.2 退出规则

1. 正在文字选择/批注操作：先结束当前操作。
2. 底部面板或搜索输入打开：先关闭面板/键盘。
3. 全屏：返回一次退出全屏，保留文档和位置。
4. 普通阅读：返回文档列表，并保存阅读状态。

跳转历史通过可见“返回阅读处”按钮或工具栏返回箭头处理，不无限劫持 Android 系统返回。页面内链接跳走后，可一键回到原来的段落。系统返回和历史回跳要用不同的清楚含义。

### 3.3 全屏细节

- 不锁住系统导航，不对整个屏幕申请手势排除。
- 导出、打开其他应用、输入文字、外部链接后返回，恢复到进入前的全屏状态。
- 横竖屏切换保留视口；分屏/桌面窗口下接受系统标题栏存在，不伪造“永久隐藏”。
- 可选页数胶囊、时间、电量；默认不放一排常驻悬浮按钮。
- 选择“保持亮屏”只在阅读器可见时有效；切后台立即恢复系统策略。

## 4. 翻页、缩放与选择的手势规则

### 4.1 普通阅读

| 手势 | 默认动作 |
| --- | --- |
| 单指水平滑动，适页/适宽且无水平溢出 | 横向分页模式下翻页 |
| 单指上下滑动 | 连续模式滚动；横向模式中，放大页内可垂直平移 |
| 双指捏合 | 缩放当前页，不触发分页 |
| 双击 | 在当前定位点放大到易读比例；再次双击回到当前适配方式 |
| 单击中部空白处 | 显隐应用工具 |
| 长按文字 | 文字选择；无文字层时提供当前页/区域 OCR |
| 点击链接 | 页面/网页链接动作，保留返回阅读处 |
| 音量键 | 默认维持系统音量；用户可开启翻页 |

不要把“左右滑页”简单叠加在现有缩放手势外。当前页放大且仍可水平平移时，优先平移。到边缘后默认需要抬手再滑一次才翻页，避免阅读表格时误跳页；高级设置可允许连续越边翻页。

设计起点可用水平位移约 24 dp、方向比约 1.3 作为手势判定的试调范围，最终以系统 Pager 的阈值及实际触摸体验为准；这些数字不是测得的最佳值。短抖动、斜向滚动、手写笔落点不应误判翻页。

### 4.2 批注与手写

- 显式进入批注模式后，笔尖用于书写；手指用于平移/双指导航的行为可设置。
- 默认不让“画一条线”同时翻页；提供清楚的手掌/浏览工具。
- 文本高亮模式允许锁定连续高亮，也允许一次选择后退出；原生批注与图像涂画分开。
- 两指撤销、三指重做等可选，保留可见按钮，不能只靠隐藏手势。
- 工具栏显示当前模式，退出时自动保存草稿；导出前可继续编辑。

Flexcil 与 PDF Expert 的笔模式导航说明表明，阅读与书写必须分别拥有手势，不能只靠事件消费顺序碰运气。[KN04][RD02]

### 4.3 可自定义，但默认稳定

可调整点击翻页区域、左右手、长按行为、音量键、边缘翻页、双击目标缩放、页间距、翻页动画。必须提供恢复默认与冲突提示；同一个手势不能同时绑定两个需要互斥的动作。高级选项收进二级面板，初次阅读不要求配置。

## 5. 高清阅读与性能

### 5.1 渲染分层

1. **页面占位与尺寸**：先得到页数、当前页尺寸与基础布局，不等待全文抽取。
2. **基础预览**：当前页立即显示较低分辨率清晰轮廓。
3. **可见区域高清块**：根据屏幕像素、缩放和裁边，渲染当前视口的图块；用户移动后替换所需块。
4. **有限预取**：横向预取前后各一页的基础图；快速拖页时取消过期任务。
5. **文字/链接覆盖层**：与渲染共享坐标，搜索框、选择框、批注位置一致。

放大后不能继续仅拉伸 1100 px 旧图。也不能一次把 500 页渲染成高分辨率 Bitmap。缓存以可见页和内存预算驱动，低内存设备缩减预取；细节在停止缩放后渐进变清晰，过程中保持已有图块不闪白。

缓存键至少包含文档版本、稳定页 ID、渲染比例档、裁边/旋转和图块区域。纯夜间滤镜尽量在显示层完成，避免为每种主题复制整套页面位图。关闭文件时取消任务，迟到结果不能显示到下一份文档上。

### 5.2 引擎选择

- 近期保留现有 `PdfRenderer` 基础路径，先把分页、状态和工具布局做好。
- 统一 `ReaderDocument` 接口，封装页尺寸、渲染、文本、链接、目录、搜索、表单与关闭。
- AndroidX PDF 的最新核对是 `1.0.0-beta01`；新发布记录已将部分阅读/渲染能力回移到 minSdk28，而较旧集成指南仍写 API31+扩展13。不能只照旧文章决定兼容范围。[AN01]
- PaperForge 当前 minSdk26，因此即使采用新库，也需要 API26/27 回退；Compose、OCR、编辑等 API 的实验状态和编译 SDK/AGP 要分别核对。
- PDFium/MuPDF 等作为有依据的候选，做短期原型后再决定；不为得到横向翻页直接重写所有 PDF 操作。

新引擎原型只回答几个问题：放大是否清晰、文字/链接是否正确、是否支持所需分页、低版本能否运行、包体与内存是否可接受。超过 1–2 人日没有确定收益，先继续现有引擎改进。

### 5.3 打开与长文档

打开来自系统文件管理器的 PDF 不必先跳首页。只读浏览默认可以不加入永久文档库；是否保存到库由用户选项决定。文件 URI 不可随机访问时，缓存到临时可定位文件并显示进度；权限失效时直接允许重新选择原文件。[AN05]

页数多时缩略图懒加载、目录渐进构建、搜索分批返回。任务中心与阅读器不能互相锁住；后台压缩正在运行，仍可阅读另一份本地 PDF。

## 6. 阅读位置与文档身份

保存：稳定文档 ID、文件内容版本、稳定页 ID、源页号、当前页序、页面内归一化锚点、缩放/适配方式、布局/阅读方向、显示裁边、主题覆盖和最后打开时间。

旋转屏幕后按页面锚点恢复，不按旧屏幕像素偏移硬套。修改页序后依据页 ID 回到原页；页被删除才回到最近可用页。外部文件内容变化时重新识别版本，保留旧书签供迁移，不把“文件同名”当作同一版本。

应用进程退出后位置应恢复。写入状态做轻量节流，离开页面及时落盘，不每一帧写数据库。主列表显示可选进度“读到 42 / 168”，但不把打开文件当成修改内容。

## 7. 页码、目录与导航

PDF 的第 15 个物理页面可能印着“1”，也可能是罗马数字。页码输入应同时支持 PDF 页面索引和页面标签，显示例如“正文 1 · 第15/168页”；搜索和书签链接用稳定页身份，界面给人能理解的标签。

近期：页数胶囊可点击跳页、缩略图网格、搜索上一处/下一处、上次阅读恢复。之后：导入大纲、手动书签、目录编辑、页面标签、跳转历史和跨文档标签页。

- 缩略图支持长按多选，跳转和管理是两个模式，防止点页时误选中。
- 目录项保留层级和长标题换行；支持搜索目录。
- 页面书签、文本高亮和文档收藏区分图标与名称。
- 搜索结果同时显示命中片段、页码和当前第几处；输入不阻塞，短时间停顿后查找。
- 可选忽略大小写/空白、全词和正则；默认简单搜索。中文短词和中英混排编号单独处理。
- 找不到文字层时给“识别当前页 / 识别全部”快捷项，不显示一个长期无结果的搜索框。

## 8. 文本选择、复制与链接

1. 先利用原生文字，原生文字不可用或质量明显异常再给 OCR 选项。
2. 选择范围支持句/段、拖动手柄、跨页逻辑选择、复制、搜索、翻译、朗读和摘录。
3. 扫描件文字框必须跟随旋转、缩放和临时裁边；改了几何或曲面后旧 OCR 不可照旧覆盖。
4. 复制提供“保留换行 / 合并段落 / 带来源”，合并换行不改变文字本身；中英文断词规则分开。
5. 图表可区域截图，选文字与选图有明确切换；截图可含/不含批注。
6. 链接长按可复制地址；内部跳转保留返回原处；电话、邮件等动作由用户点击触发。

社区中已出现“TXT 几乎正确，但 PDF 框不对、复制句子乱序”的报告，因此这部分是 OCR 交付的一部分，不能只检查全文是否能搜索。[CM08][CM09]

## 9. 夜间、纸色、裁边和重排

### 9.1 外观

界面深色与 PDF 页面颜色是两项设置：系统深色只改变应用外壳，用户再选择纸白、暖纸、灰纸或反色。反色可能影响照片/彩色图表，提供“保留图片原色”或按页关闭；不把所有彩色内容强行取反。[KN05]

亮度沿用系统；可选阅读页临时调节，退出后恢复。显示裁边是可撤销视图，不改 CropBox、不删除原内容；允许奇偶页不同边距和当前/全篇应用。

### 9.2 重排

先支持单栏、清晰文字层的文档，再扩展双栏和 OCR 页。重排是临时视图，不等于已经得到结构正确的 DOCX/EPUB。每个文本块保留源页链接，标题层级/图注/表格/公式可回到原图看。

缺失阅读顺序时保留原布局；复杂图表、公式、票据不强制重排。提供字号、字距、行距、段落间距、边距和字体；跨页移除页眉/页脚可预览、可撤销，不删除原件。

Adobe Liquid Mode 自身也有语言、扫描件、复杂版面、页数/大小等限制，说明任意 PDF 的重排不是一个开关就能保证成功。[RD05][RD06]

## 10. 朗读、摘录与学习扩展

P2：利用可用文字层调用系统 TTS，支持从选中段落开始、暂停/继续、语速、前后段与高亮跟读。显示声音是否已安装、是否需要网络，不默认下载整套声音。锁屏控制与耳机按键作为后续增强。

P2：摘录卡片包含原文/截图、自己的笔记、文档 ID、页码和区域；点击回原文。导出 Markdown 带来源链接、DOCX 汇总或标准 PDF 批注。数据库内笔记与嵌入 PDF 的批注分清，避免换个阅读器便看不到。[KN01][KN02]

P3：双文档对读、同步滚动、概念链接、复习卡和按页码引用的摘要。默认阅读器不出现常驻 AI 输入框或学习画布；在学习档案中按需启用。

## 11. 自定义项目

| 层级 | 可调项目 |
| --- | --- |
| 全局 | 初始阅读模式、主题、默认缩放、页间距、工具自动隐藏、保持亮屏、音量键 |
| 本文档 | 布局/RTL、封面单页、临时裁边、色彩、缩放保留、书签、阅读位置 |
| 工具 | 底栏固定动作、批注快捷颜色、线宽、选择后菜单顺序 |
| 手势 | 边缘点击、翻页方向、双击、放大到边缘后的翻页规则、左右手 |
| 设备 | 窄屏/平板布局、手写笔与手指分工、键盘快捷键 |

每项都能恢复默认。设置导入导出包含阅读配置，但不把设备专有的 URI/临时文件路径硬迁移到另一台机器。

## 12. 键盘、鼠标、平板与无障碍

方向键/PageUp/PageDown 翻页；Home/End 到首末；Ctrl+F 搜索；Esc 退出面板/全屏；Ctrl+L 跳页可作为候选，按 Android 实际焦点冲突调整。鼠标滚轮连续滚动，Ctrl+滚轮缩放，不能在输入框内抢快捷键。

平板宽屏可左目录/中正文/右笔记，窄屏把面板改为底部抽屉。折叠屏折痕不压在文档正中；窗口变化不重开文件、不丢文字选择和位置。文字按钮与图标具备语义标签，关键触控区域至少 48 dp；阅读操作都有按钮替代隐藏手势。[UI01][UI02]

## 13. 近期完成定义

v0.6.0 必须完成：

- 横向单页和纵向连续可切换；文档设置可以记住。
- 显隐工具与全屏，退出不误关文档；支持系统边缘导航。
- 捏合/平移/翻页手势按上述规则分工，放大读表格不误跳。
- 最近打开和阅读位置持久保存，旋转和重新进入不跳回第一页。
- 移除常驻转换按钮条，让阅读画布成为主体；工具仍可从菜单快速找到。

v0.7.0 优先完成：高清分块、原生文字选择与链接、目录/书签、搜索渐进返回、主题/裁边、必要引擎适配。高级重排、朗读、双页和学习扩展按实际价值继续。

只需几条有用的检查：一本长 PDF 反复翻页与放大、一次全屏与返回、一次进程重启位置恢复、一个带旋转/页面标签/链接的 PDF、一个扫描件 OCR 选中文本。界面文案或颜色小改不重跑这些全链路。
