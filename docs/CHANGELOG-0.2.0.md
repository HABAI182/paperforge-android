# 0.2.0 · 扫描、OCR 与本地工具箱

用户反馈：扫描只能手动调四角，OCR 不可用。优先修复实际扫描/识别链路，减少重复询问与大规模测试；按非商用本地应用继续实现。

## 核心修复

- 纸边检测从单一 Canny 阈值改为低阈值边缘 + Otsu 正反亮度掩膜，多尺度四边形拟合与面积/形状评分。支持弱对比纸面；自动拍摄默认开启，照片和相册图自动裁切，编辑页提供「自动裁边」。
- 相机加入点击对焦、变焦、曝光、低光提示、缩略图与重拍替换；质量优先拍照。滤镜增加局部光照归一化去阴影与白板模式，增强限制锐化，避免灰色光晕。
- OCR 优先使用裁切旋转后的原色高分辨率图，避免显示滤镜或亮度参数抹去细字。识别过少再尝试增强，空结果再尝试 Latin/侧转；保留 native 任务输入直到真正完成。
- 保存 OCR 行四角与文字，支持单页/全部识别、校正、复制、TXT、中文可搜索 PDF。修复 Noto 共享 glyph 的反向 Unicode 映射，防止「文」复制为康熙部首「⽂」。

## 新增功能

- 扫描与 PDF 网格拖拽排序、批量旋转/删除，扫描复制、滤镜批量套用、长按原图对比、双页中缝分割、证件两面 A4 合版、JPG/PNG 包。
- PDF 阅读搜索高亮、缩略图导航；合并顺序调整、逐页拆分、裁边、空白页、2/4 合 1、水印、页码、元数据、图片提取、JPG/PNG、TXT/MD/HTML/文字 DOCX。
- 画笔、高亮框、矩形、中文文字、手写签名与复用、批注草稿。输出固定到 PDF 副本，不冒充原生文字编辑或证书签名。
- 安全脱敏创建全新图片 PDF，移除原内容流、隐藏文字、附件与元数据。源文档仍留在应用中。
- AES-256 PDF 打开密码和打印/复制权限；密码导入后建立可编辑副本，密码不持久化。基础 AcroForm 字段填写，中文值配置嵌入字体。
- 文件夹、标签、收藏、内容匹配搜索、回收站；Room 1→2 迁移、持久编辑历史；离线 ZIP 备份和追加恢复，含原图、历史、OCR、批注和签名。
- PDF 工具由 WorkManager 执行；ZIP/DOCX/HTML 等使用正确 MIME 另存和分享。

## 验证范围与接续

针对弱对比自动裁边、中英 OCR、中文透明文字层与四种页旋转搜索、批注/安全脱敏/加密、页面工具、中文表单、编辑历史与备份恢复做必要回归；具体结果与文件校验见 TEST_MATRIX 和 acceptance/v020。

曲面书页展平、去手指/去手写、超分与模糊恢复、表格结构和高保真 Office 转换、原 PDF 文本对象编辑、证书签名与 XFA、英文 UI 尚未实现。双页分割不等同曲面展平，文字 DOCX 不还原原排版。实际手机纸张质量、复杂 PDF 与大文件性能仍需独立样本验证。
