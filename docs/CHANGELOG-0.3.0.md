# 0.3.0

## 扫描与识字

- 修正高分辨率区域解码、EXIF 四角映射与透视后的物理宽高比，提供独立 DPI 档位。
- 多通道候选评分和静态照片窄带直线精修代替最大轮廓偏置；拍摄后重新检查原照片四角。
- 自动增强保留颜色，加入可调彩色照明场校正和按尺度调整的 Sauvola 黑白；深色标题与红色标记有单独证据。
- OCR 记录行/元素四角、模型分数、方向、引擎版本和原始候选；共享识别器串行处理，取消时等 native 任务完成再释放输入。
- 依据文字角度校正方向，低分和小字使用有限替代视图；加入未重采样原图候选与重复标题一致性校对，所有纠正只使用同页实际观察到的候选。
- OCR 可编辑结果去掉逐行低分长警告。相机提示简化，AF 回调超过1.2秒时可由画面清晰度接管；手动快门始终独立可用。

## PDF 与文档

- 扫描 PDF 使用不透明 RGB、真实单通道灰度、1-bit Flate 黑白；移除无意义 SMask。
- 压缩递归处理嵌套 Form 图片并按实际放置尺寸降采样，保留原生内容流/链接/表单；不适合的对象跳过并生成报告，不变小则复制原件。明确的扁平化入口单列。
- 段落 DOCX 可选原页参考图；嵌套 PDF 图片提取去重；中文 FTS4 全文搜索；可选系统应用锁和防截图。
- 最近文档同时提供回收站和直接删除；后者一次确认永久移除应用内原图、历史与记录。
- 首页缩短展示，扫描、导图、识字、压缩可直接进入；编辑页主工具前置；阅读器增加 OCR/Word/图片/页面快捷键，PDF 工具箱支持搜索和分类。
